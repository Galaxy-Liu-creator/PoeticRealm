# 诗境 · 一卷山河

**Poetic Realm · A Scroll of Mountains and Rivers**

> 循诗入境，展卷见山河。

以浮动诗词卡片为入口，通过按意象设计的转场进入有真实材质、光照与自然动态的三维山水；读诗、观景、收藏，再翻页回到诗词总览。

> **当前：2026-10-01 R1 桌面 UI 首版。** 用户授权核对文档后代码还原，采用 [当前混合版本视觉清单](docs/design/README.md)。已实现总览、收藏、个人中心、三诗静态预览、账号三页与拉幕；收藏、资料、头像和偏好保存在当前浏览器。账号服务等待用户选择，实时三维和诗境专属转场留在 R2/R3。实现与验证见 [R1 报告](docs/plans/R1-UI还原/report.md)，续接状态见 [HANDOFF](HANDOFF.md)。

## 新版目标与阶段

- 打开即见诗词总览：全宽山水题头、行书“诗境·一卷山河”、绢纸山影与竹叶底景、三张对齐诗卡，以用户指定 v09 原图为准。
- 按诗意入场：中央火烧、右上广域碎雪、云水揭幕；诗境中竖排读诗、观察真实山水。
- 顶部导航：总览、收藏、个人中心；首页无返回，诗境翻页返回总览。
- 按用户新原图设计个人中心，以及登录/注册与全屏幕布入口；认证与数据保存方案实施前明确，当前没有账号服务。
- 已按指定稿开始代码还原；设计归档、当前实现和最终实机验收分别记录。

## 技术与边界

Blender + Three.js（WebGLRenderer，three.js 0.186.1 精确锁定）+ GLSL + TypeScript + Vite + GSAP。复杂主体在 Blender 制作；自然环境用可复用 JS / Shader 系统。全局时钟、种子随机、GLB 机位来源与资产许可要求继续保留。

当前资产契约 v0.1 仍有效；写实 PBR 输入等需在后续实施时同步更新 CONTRACT、校验脚本、资产与加载代码，本轮不更改接口。

## 运行 UI 与保留的技术原型

```bash
npm install
npm run dev
npm run build
npm test
npm run check:contract
```

`dev` 默认展示新 UI。`node tools/verify-ui.mjs` 在已运行的本地 Vite 服务上复验页面与异常，截图保存在 R1/assets。`check:contract` 仍是未完成的原计划任务，不能凭退出成功声称完整契约校验已实现。

显式 `?scene=<id>&t=<秒>`、`?q=high|mid|low` 或 `?debug` 仍进入独立保留的 P0，覆盖普通 hash 页面，保留 `window.__POETIC__`。不带这些参数时使用 `#/`、`#/favorites`、`#/profile`、`#/poems/<id>`、`#/account`、`#/login`、`#/register`。

`.blend` 等源资产用 Git LFS 管理，克隆时需准备 Git LFS。制作端命名、导出、预算见 [CONTRACT](docs/CONTRACT.md)。
