# 诗境 · 一卷山河

**Poetic Realm · A Scroll of Mountains and Rivers**

> 循诗入境，展卷见山河。

以浮动诗词卡片为入口，通过按意象设计的转场进入有真实材质、光照与自然动态的三维山水；读诗、观景、收藏，再翻页回到诗词总览。

> **当前：2026-10-01 方向重设与 UI 审批阶段。** 新版文档 v3 与桌面网页续稿已完成，**[首页 v06](docs/design/2026-10-01-v3/v06/screens/S01-home-desktop.png)** 的三张卡片已统一尺寸；页面与转场仍待逐稿审批。现有运行代码仍是旧 P0 技术验证原型，不是新版 UI。审批入口见 [docs/design/README.md](docs/design/README.md)。

## 技术与边界

Blender + Three.js（WebGLRenderer，three.js 0.186.1 精确锁定）+ GLSL + TypeScript + Vite + GSAP。复杂主体在 Blender 制作；自然环境用可复用 JS / Shader 系统。全局时钟、种子随机、GLB 机位来源与资产许可要求继续保留。

当前资产契约 v0.1 仍有效；写实 PBR 输入等需在后续实施时同步更新 CONTRACT、校验脚本、资产与加载代码，本轮不更改接口。

## 运行现有技术原型

```bash
npm install
npm run dev
npm run build
npm test
npm run check:contract
```

`dev` 展示的是旧 P0 验证内容。`check:contract` 仍属于未完成的原计划任务，不能仅凭命令存在就声称完整契约校验已实现。

已有调试入口：`?scene=<id>&t=<秒>`、`?q=high|mid|low`、`?debug` 与 `window.__POETIC__`。新版路由与这些入口的整合尚未实现。

`.blend` 等源资产用 Git LFS 管理，克隆时需准备 Git LFS。制作端命名、导出、预算见 [CONTRACT](docs/CONTRACT.md)。
