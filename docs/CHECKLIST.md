## R1 · 首页 / 导航 / 本机资料

- [ ] 打开即能选诗，无黑屏点击门禁、无强制书房片头
- [ ] 首页背景非纯黑白，标题区域与总览区域明确分开
- [ ] 卡片有轻微浮动，聚焦停稳；收藏不误触进入
- [ ] 首页无返回；所有非首页有返回；深链接刷新与无效 id 有处理
- [ ] 收藏新增 / 取消同步到总览、详情、收藏页与个人中心；无虚构收录项
- [ ] 个人资料保存、取消、刷新、无痕 / 禁用存储行为清楚
- [ ] 头像本地预览和裁切；有效格式、超限、损坏图片测试；不对外上传
- [ ] 空收藏有可操作入口；持久化失败不显示保存成功
- [ ] 键盘 / 触控可用，焦点明确，表单有 label

## R2 · 枫桥写实与往返

- [ ] 先用浏览器质量小样验证石 / 木 / 瓦 / 江面 / 阴影关系；不是只看 Blender 离线图
- [ ] 需要的 PBR / 地形契约先迁移，校验、导出、资产和加载同步
- [ ] 唐风寺、桥、舟与植被有可信尺度和结构，无 P0 粗体块冒充成品
- [ ] 火烧从中央揭幕，有不规则纸缘 / 少量余烬，无黑帧、爆闪和传送门观感
- [ ] 目标资源就绪并成功渲染首帧后才揭幕；错误、取消、快速连点不会卡死
- [ ] 月落、渔火、水反射、薄雾可见；文字在夜景中清楚
- [ ] 钟声按 GLB 距离计算，波前抵达时播放；说明是艺术化声传播
- [ ] 诗境返回使用有卷曲 / 背面 / 阴影的翻页，总览滚动与焦点恢复
- [ ] 浏览器后退 / 前进与站内按钮状态一致，无历史死循环
- [ ] 多次进出后纹理、监听、音频与渲染目标释放，没有持续增加

## R3 · 江雪 / 白帝城

- [ ] 风雪从右上向左下，碎而广，覆盖层交接连续，不是几个图标后硬切
- [ ] 雪景非纯白，山江有层次，孤舟 / 蓑衣有材质，字不遮主体
- [ ] 白帝城有晨光彩云与城的视觉提示、峡谷纵深、舟行与左右猿声
- [ ] 水、雪、雾、风是由同一时钟驱动的可复用系统
- [ ] 三场景质感与情绪明显不同，不能只替换同一场景滤镜
- [ ] 所有正式收录卡片都能进入可用场景
