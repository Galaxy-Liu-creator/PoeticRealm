# STORYBOARD · 新方向分镜草案

> 2026-10-01 · v3 对应稿，**待生成设计稿和用户审批**。以下是设计目标，不是已运行的时间线。
> 转场用归一化进度 `p`；诗境时间 `t_scene` 从正式进入诗境起算，由全局时钟推导，不另用真实时间。

## A. 总览常态

| 部分 | 画面 | 动态 / 交互 |
|---|---|---|
| 顶部导航 | 诗词总览、我的收藏、个人中心 | 首页无返回；其余页面有返回 |
| 暗色山水题头 | 行书“诗境·一卷山河”，山影与江水 | 缓慢雾动、水纹、低强度流光；标题稳定 |
| 较亮山水总览区 | 三首浮动诗卡，不是纯黑白底 | 小幅漂浮；悬停 / 聚焦停稳；点击进入，收藏不触发进入 |

## B. 火烧入场 · 枫桥提案

建议总长 1.6 秒，资源加载时间不计入。

| 进度 | 画面 | 验收关注 |
|---|---|---|
| 0% | 完整总览，已选卡片聚焦 | 背景和文字没有提前消失 |
| 25% | 中央不规则焦边形成小开口，内侧见夜江 | 开口露出的是真实目标帧，不是黑色占位 |
| 50% | 开口扩大，细火缘与少量余烬，寺 / 舟逐渐可见 | 非爆炸、非仙侠传送门；导航遮挡逻辑清楚 |
| 75% | 仅外围残留来源页，火势收敛 | 无闪白、无多次切场景 |
| 100% | 完整枫桥，诗文和操作清楚，火缘退净 | 输入解锁，目标诗境开始自己的时间线 |

## C. 广域风雪入场 · 江雪提案

建议总长 2.1 秒。

| 进度 | 画面 | 验收关注 |
|---|---|---|
| 0% | 来源总览 | 保持可读 |
| 25% | 碎雪从右上向左下进入，覆盖多个象限 | 不只是右上角几个装饰雪花 |
| 50% | 近远雪层加密，雪雾遮罩形成连续覆盖 | 不能在稀疏雪花后突然切底图 |
| 75% | 雪雾渐透，冷青江水、远山、孤舟显现 | 来源与目标交接无硬切 |
| 100% | 江雪与诗文完整呈现，雪势回归安静 | 字可读，舟可见，雪不是满屏白片 |

## D. 云水入场 · 白帝城提案

建议 1.5 秒；0% 来源 → 25% 云水沿峡谷方向铺开 → 50% 形成遮挡 → 75% 显露晨光峡谷 → 100% 目标。图稿需与火、雪不同，但沿用相同的加载和取消语义。

## E. 翻页返回总览

建议 1.1 秒，从左向右翻起。

| 进度 | 画面 | 验收关注 |
|---|---|---|
| 0% | 当前诗境，返回被激活 | 捕获的是当前画面而非默认封面 |
| 25% | 左侧纸页卷起，露出其下总览 | 有真实卷曲形态，不是平移 |
| 50% | 纸页正面、背面、阴影与总览同时可见 | 诗文 / 导航的 DOM 合成无残影 |
| 75% | 诗境页接近翻离，总览大部出现 | 总览背景已就绪 |
| 100% | 回到总览原滚动位置，焦点回原卡片 | 无返回按钮，收藏状态保持 |

浏览器后退到总览同样走此流程；收藏 / 个人中心普通返回可使用短淡入淡出。reduced-motion 时不执行大幅卷曲。

## F. 诗境演出示意

下面以每句约 8 秒作构图提案；精确时间和相机新增引用须在实施阶段通过 CONTRACT 校验，不把表格当作已有节点齐全的声明。

| 场景 / 时间 | 诗句 | 机位意图 / 已有契约节点名 | 画面与声音 |
|---|---|---|---|
| 枫桥 0–8 s | 月落乌啼霜满天 | `CAM_moonset` | 半月低落、乌啼、冷江薄雾；左上诗文留白 |
| 枫桥 8–16 s | 江枫渔火对愁眠 | `CAM_riverbank` | 枫岸、暖渔火、真实倒影与客船 |
| 枫桥 16–24 s | 姑苏城外寒山寺 | `CAM_temple` | 寺与钟楼从薄雾中清楚显出，建筑唐风 |
| 枫桥 24–32 s | 夜半钟声到客船 | `CAM_boat` / `FOCUS_bell` | 波前从 `EMIT_bell` 出发，到船时响钟；延迟按节点距离计算 |
| 江雪 0–8 s | 千山鸟飞绝 | `CAM_birds` | 层叠雪山、寂静，鸟影退去 |
| 江雪 8–16 s | 万径人踪灭 | `CAM_path` | 雪岸与山路的空间关系，雾中无行人 |
| 江雪 16–24 s | 孤舟蓑笠翁 | `CAM_fog` | 从留白中见舟与蓑衣，材质和比例可信 |
| 江雪 24–32 s | 独钓寒江雪 | `CAM_boat` | 停留、静雪、细水动，声音渐轻 |
| 白帝城 0–8 s | 朝辞白帝彩云间 | `CAM_city` | 晨光、城轮廓、彩云；不是无城的普通峡谷 |
| 白帝城 8–16 s | 千里江陵一日还 | `CAM_follow` | 轻舟与江流，稳定提速 |

| 白帝城 24–32 s | 轻舟已过万重山 | `CAM_exit` | 视野展开，近景视差减弱，无滚转 |

## G. 证据要求

- 设计阶段：页面原稿 + 火 / 雪 / 云水 / 翻页关键帧板，标明“概念分镜”。
- 实现阶段：在固定 seed 与时间码下截帧，录短视频检查连续性；只看静帧无法证明动态正确。
- 同时验证：低档、reduced-motion、窄屏、加载失败、连点、返回取消、切页后的资源释放。
