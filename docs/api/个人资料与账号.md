# 个人资料与账号接口

接口前缀 /api/v1。全部需要当前页面 X-POETIC-TOKEN；写操作还需当前 CSRF。身份只取认证上下文，不接受客户端 userId 选择账号。敏感响应继续 no-store。与 [认证接口](认证接口.md) 的关闭/刷新及显式登录规则一致。

| 方法与路径 | 行为 |
|---|---|
| GET /account/settings | 返回当前账号的 `{library}`，未同步过为 null |
| PUT /account/settings | 校验并事务保存整个 LibraryDocument，更新生日/性别；返回 `{library}` |
| GET /account/devices | 返回该账号有效页面登录记录：opaque id、User-Agent、登录/最近活动时间、current；不含 token、lease 或哈希 |
| POST /account/remember | `{remember}` 开关本浏览器 30 天 HttpOnly 凭据；其他浏览器凭据保留；不自动登录 |
| POST /account/devices/revoke-others | `{remember}` 撤销其他页面访问和所有旧持久凭据，按选择为当前浏览器重新发凭据；当前访问保留 |
| POST /account/password | `{currentPassword,password}` 校验原密码和 8–20 位至少两类字符的新密码，BCrypt 更新后撤销全部页面/持久凭据；当前页重新登录 |
| GET /account/export | 返回 exportedAt、本人安全 AccountView 与 library；不含密码、哈希、令牌、Cookie 或其他人的数据 |
| DELETE /account/history | 永久清空本人浏览历史，保留收藏、资料和设置 |
| DELETE /account | `{password,confirmation}`：原密码和完整账号确认；事务删除本人账号、资料与持久凭据，撤销全部页面访问 |
| GET /profiles/{username} | 仅登录用户可读；公开主页受 profileVisibility 控制，收藏/足迹分别受自身权限控制；不返回生日/认证信息 |
| GET /profiles?query=… | 最多返回10条开启 searchable 且主页公开的账号；有限候选检索，不暴露隐藏账号数据 |

LibraryDocument 延续 version=1。profile 含 name/gender/bio/avatar/birthday；preferences 含 dark/motion/transitions/music/sound/recommend/fontSize/startPage/sort/theme；privacy 含 profileVisibility/favoritesVisibility/visitsVisibility（everyone/private）、searchable/personalization/saveHistory。收藏限定当前三首诗，历史至多50条，日期和头像 data URL 有限长校验。旧本机文档缺失字段由前端补默认，新增隐私默认私有且关闭搜索/个性化授权。关闭历史保存会清空历史并停止后续记录。

登录后加载数据库资料；首次同步迁移该账号原有本机缓存，游客不导入。收藏/浏览/偏好变化同步写回。刷新保留原 hash；startPage 只影响显式登录成功后的入口。推荐仅在 recommend 与 personalization 均开启时使用本地收藏及浏览信号，未建立外部画像服务。

设备记录代表页面令牌，User-Agent 是客户端声明，位置未采集，不伪造 IP 地理信息。页面令牌仍在单实例内存，服务重启后失效，关闭通知与30分钟兜底过期保持。

Flyway V2 仅新增 account_settings（user_id 外键、LONGTEXT 文档、updated_at）；保留已执行 V1。上线先备份数据库并验证迁移，再发应用；代码回退保留 V2 表与数据，不执行自动删表。密码修改与账号注销会立即影响访问，注销数据不能靠代码回退恢复，需用户明确确认；备份恢复由运维另行选择。密码找回、邮箱验证、分布式限流和多实例令牌存储仍待后续。
