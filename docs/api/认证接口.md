# 认证接口契约

2026-10-02。Spring Security服务端会话，接口根/api/v1；前端只在内存保存当前身份与CSRF token，不把密码/认证凭证写浏览器存储。配置与测试见 [backend说明](../../backend/README.md)，当前进度见 [HANDOFF](../../HANDOFF.md)。

## 流程与接口

| 方法/路径 | 请求 | 成功响应 |
|---|---|---|
| GET /auth/csrf | 无 | 200：headerName、token |
| POST /auth/register | 注册JSON，CSRF请求头 | 201：UserView，不自动登录 |
| POST /auth/login | username、password、remember，CSRF请求头 | 200：authenticated=true、user；设置会话/可选持久Cookie |
| GET /auth/session | Cookie | 200：authenticated、user；游客为false/null |
| POST /auth/logout | Cookie，CSRF请求头 | 204；撤销当前会话及该账号全部持久登录凭证 |
| GET /me | 已认证Cookie | 200：当前UserView；不接受客户端userId选择身份 |

浏览器先GET/auth/csrf，携带其返回的X-CSRF-TOKEN提交修改请求。默认掩码token保留BREACH防护；登录成功时会话ID更换并清除旧CSRF，前端下一次修改重新获取。退出同样清除token，匿名重新请求后仍可登录。仅对CSRF_INVALID在执行端点前拒绝的请求刷新token重试一次；密码错误不自动重试。所有认证响应禁止缓存；401/403使用JSON，不重定向HTML登录页。

注册请求示例（仅测试数据）：

```json
{
  "username": "诗境旅人",
  "password": "Testpass123!",
  "birthday": null,
  "gender": "",
  "agreement": true,
  "agreementVersion": "2026-10-02-dev"
}
```

用户名4–16位，中文/英文/数字/下划线；用户名查找/唯一键使用NFKC及大小写归一化，原显示名保留。当前不支持邮箱登录。密码8–20位，字母、数字和特殊字符至少两类；服务器独立校验，以BCrypt成本12保存哈希。生日可选且不能在未来；性别可选，空/男/女/其他。agreement必须主动为true，版本必须匹配当前开发测试说明；正式协议还未发布。

UserView只包含id、username、birthday、gender、createdAt，不序列化Entity或密码哈希。登录返回：

```json
{
  "authenticated": true,
  "user": {
    "id": 1,
    "username": "诗境旅人",
    "birthday": null,
    "gender": "",
    "createdAt": "2026-10-02T00:00:00Z"
  }
}
```

## Cookie与错误

JSESSIONID为HttpOnly会话Cookie，30分钟无活动过期；POETIC_REMEMBER为HttpOnly、SameSite=Lax的30天持久凭证，自动恢复时旋转token并续期。生产HTTPS两种Cookie启用Secure。未选择remember不发行持久凭证；退出清Cookie及数据库该账号持久token，重放已撤销token不能恢复。退出不撤销其他设备已存在的普通短会话；全设备会话管理尚未提供。

统一错误：`{ "code": "...", "message": "...", "fields": {} }`。

| 状态/代码 | 行为 |
|---|---|
| 400 VALIDATION_FAILED/WEAK_PASSWORD/INVALID_REQUEST/AGREEMENT_CHANGED | 字段、密码、JSON日期或版本不正确 |
| 401 INVALID_CREDENTIALS | 用户不存在和密码错误使用同一消息 |
| 401 UNAUTHENTICATED/SESSION_EXPIRED | 无会话或身份已失效 |
| 403 CSRF_INVALID/FORBIDDEN | token缺失/过期或无权限 |
| 409 USERNAME_TAKEN | 同名或归一化同名冲突 |
| 429 LOGIN_THROTTLED | 15分钟内同用户名8次或同来源地址30次失败后暂时限制 |

不信任客户端提供的转发IP；反向代理下需先落实受信任代理配置再调整限流。节流状态仅单进程内存。数据库与服务器错误不向前端披露内部堆栈/凭据。

## 本机数据与未实现范围

身份由服务器恢复，不从localStorage推断。游客沿用poetic-realm.library.v1；账号采用独立的.account.{id}键。登录不自动导入游客头像、资料或收藏，退出恢复游客原数据；账号间不混读本机数据。头像/收藏/昵称编辑与足迹尚未云同步，界面明确标注。本机用户名记忆保留原行为，并与真正服务器持久登录区分。

未实现邮箱验证、找回密码、云头像、账号资料/收藏API和全设备会话管理。MySQL部署尚待用户配置；自动验证使用H2 MySQL兼容模式，不作为MySQL实测证明。

实现依据：[Spring Security认证架构](https://docs.spring.io/spring-security/reference/servlet/authentication/architecture.html)、[CSRF](https://docs.spring.io/spring-security/reference/servlet/exploits/csrf.html)、[Remember-Me](https://docs.spring.io/spring-security/reference/servlet/authentication/rememberme.html)。
