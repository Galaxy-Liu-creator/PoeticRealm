# 认证接口契约

2026-10-05。接口根 `/api/v1`。Spring Security 检查标签页访问令牌；JSESSIONID 仅保存 CSRF 状态，记住凭据的 Cookie 仅用于显式登录。访问令牌及刷新凭据只放内存和 sessionStorage，密码不进入浏览器存储。配置与测试见 [backend说明](../../backend/README.md)、[Docker启动](../Docker启动.md)，当前进度见 [HANDOFF](../../HANDOFF.md)。

## 流程与接口

| 方法/路径 | 请求 | 成功响应 |
|---|---|---|
| GET /auth/csrf | 无 | 200：headerName、token |
| POST /auth/register | 注册JSON，CSRF请求头 | 201：UserView，不自动登录 |
| POST /auth/login | username、password、remember，CSRF请求头 | 200：authenticated、user、token、lease；可选持久Cookie |
| GET /auth/remembered | 记住凭据Cookie | 200：remembered、username；仅登录表单提示，不返回访问令牌 |
| POST /auth/login-remembered | remember，记住凭据Cookie、CSRF请求头 | 点击登录后签发 authenticated、user、token、lease |
| GET /auth/session | X-POETIC-TOKEN、X-POETIC-LEASE | 验证并续接当前标签页，返回 authenticated、user、token、lease；无有效凭据为false/null |
| POST /auth/release | token、lease JSON | 204；立即停用该页面访问令牌，保留15秒刷新窗口 |
| POST /auth/logout | X-POETIC-TOKEN、CSRF请求头 | 204；撤销当前标签页及该账号全部记住凭据，清Cookie |
| GET /me | X-POETIC-TOKEN | 200：当前UserView；不接受客户端userId选择身份 |

浏览器先GET/auth/csrf，携带其返回的X-CSRF-TOKEN提交修改请求。默认掩码token保留BREACH防护；登录成功时会话ID更换并清除旧CSRF，前端下一次修改重新获取。退出同样清除token，匿名重新请求后仍可登录。仅对CSRF_INVALID在执行端点前拒绝的请求刷新token重试一次；密码错误不自动重试。所有认证响应禁止缓存；401/403使用JSON，不重定向HTML登录页。

`/auth/release` 是唯一免 CSRF 的修改接口：随机 token 和 lease 必须同时匹配，且仅能停用自己的页面凭据，无数据修改或登录能力。pagehide 通过 sendBeacon 调用；旧文档的延迟通知无法撤销续接后的凭据。关闭令牌立即失去访问权限；刷新在15秒内携带同标签页 lease 换发新令牌。并发身份恢复请求在客户端合并，避免同一 lease 被重复使用。

注册请求示例（仅测试数据）：

```json
{
  "username": "诗境旅人",
  "password": "Testpass123!",
  "birthday": null,
  "gender": "",
  "agreement": true,
  "agreementVersion": "2026-10-02-dev"
}
```

用户名4–16位，中文/英文/数字/下划线；用户名查找/唯一键使用NFKC及大小写归一化，原显示名保留。当前不支持邮箱登录。密码8–20位，字母、数字和特殊字符至少两类；服务器独立校验，以BCrypt成本12保存哈希。生日可选且不能在未来；性别可选，空/男/女/其他。agreement必须主动为true，版本必须匹配当前开发测试说明；正式协议还未发布。

UserView只包含id、username、birthday、gender、createdAt，不序列化Entity或密码哈希。登录返回：

```json
{
  "authenticated": true,
  "user": {
    "id": 1,
    "username": "诗境旅人",
    "birthday": null,
    "gender": "",
    "createdAt": "2026-10-02T00:00:00Z"
  },
  "token": "<43-character-opaque-access-token>",
  "lease": "<43-character-opaque-reload-credential>"
}
```

## Cookie与错误

JSESSIONID为HttpOnly、SameSite=Lax的CSRF会话Cookie，单独携带不能访问 `/me`。POETIC_REMEMBER为HttpOnly、SameSite=Lax的30天记住凭据，读取提示及显式登录时旋转并续期，单独携带不能访问受保护API。HTTPS启用COOKIE_SECURE。未勾选remember不发行持久凭据；使用已记住凭据登录时取消勾选，会撤销该账号持久凭据。退出清Cookie及数据库该账号持久token，但不撤销其他标签页已经签发的访问令牌；其他设备退出与密码修改的撤销规则见 [个人资料与账号](个人资料与账号.md)。

新文档仅在 Navigation Timing 类型为 reload 时读取 sessionStorage；新开、深链接、复制标签页或浏览器恢复标签页仍先登录，不自动使用记住凭据。登录页显示账号及已保存密码状态（空的只读密码输入框显示圆点占位），无需再次输入，但必须点击登录。注册不自动登录。刷新验证完成后继续原 hash 页面。pagehide 已送达时访问令牌立即停用；断网、浏览器崩溃或强杀无法保证通知，后端设30分钟闲置过期。后端重启使内存访问令牌失效，数据库账号和30天凭据保留。

统一错误：`{ "code": "...", "message": "...", "fields": {} }`。

| 状态/代码 | 行为 |
|---|---|
| 400 VALIDATION_FAILED/WEAK_PASSWORD/INVALID_REQUEST/AGREEMENT_CHANGED | 字段、密码、JSON日期或版本不正确 |
| 401 INVALID_CREDENTIALS | 用户不存在和密码错误使用同一消息 |
| 401 UNAUTHENTICATED/SESSION_EXPIRED | 无会话或身份已失效 |
| 403 CSRF_INVALID/FORBIDDEN | token缺失/过期或无权限 |
| 409 USERNAME_TAKEN | 同名或归一化同名冲突 |
| 429 LOGIN_THROTTLED | 15分钟内同用户名8次或同来源地址30次失败后暂时限制 |

不信任客户端提供的转发IP；反向代理下需先落实受信任代理配置再调整限流。节流状态仅单进程内存。数据库与服务器错误不向前端披露内部堆栈/凭据。

## 本机数据与未实现范围

身份由服务器验证，不从localStorage推断。账号采用独立的.account.{id}键；旧游客库保留但不能用于绕过登录。登录不自动导入游客头像、资料或收藏；退出返回登录页，不删除账号本机资料。账号间不混读本机数据。资料、收藏、足迹、隐私和偏好同步到数据库，字段与权限规则见 [个人资料与账号](个人资料与账号.md)。本机用户名记忆只辅助表单，不产生登录权限。

未实现邮箱验证、找回密码、独立对象存储和分布式设备管理；当前设备管理覆盖本实例签发的页面令牌。单元与接口测试使用隔离H2；Docker使用独立MySQL和持久卷，不依赖宿主机数据库。多实例部署前需共享标签页凭据和限流存储。

实现依据：[Spring Security认证架构](https://docs.spring.io/spring-security/reference/servlet/authentication/architecture.html)、[CSRF](https://docs.spring.io/spring-security/reference/servlet/exploits/csrf.html)、[Remember-Me](https://docs.spring.io/spring-security/reference/servlet/authentication/rememberme.html)。
