## 1. 架构与目录

同一 Git 仓库下两个独立工程：frontend 使用现有 Vite + TypeScript + Three.js；backend 使用 Spring Boot + Maven。依赖、测试、构建独立，通过 `/api/v1` HTTP 接口通信。保留 hash 路由、锁定的 three.js、现有渲染分层、GLB 契约及 P0 调试入口。后端先用一个应用按业务包组织，当前规模无需微服务或独立授权服务器。

## 2. 本轮迁移

| 原位置 | 目标及关联 |
|---|---|
| src/public、npm 文件、index、Vite/TS 配置 | 整体迁 frontend，根不留第二份前端入口 |
| tools | 迁 frontend/tools；脚本按文件位置定位 frontend/仓库根，证据仍输出根 docs/output |
| 应用引用的 docs 图片 | 复制到 frontend/src/assets/ui，原稿不改，来源映射可追溯 |
| art | 保留根目录，导出目标改 frontend/public/assets |

运行副本不再编译依赖 docs；既有本地预览用途与发布限制保持，不因迁移自动取得发布许可。现有 node_modules 可随工程移动后验证；干净环境按原锁文件安装。

```bash
# 从仓库根执行
npm --prefix frontend ci
npm --prefix frontend run dev
npm --prefix frontend run build
npm --prefix frontend test
# 另一个终端启动前端后验收
node frontend/tools/verify-ui.mjs
node frontend/tools/verify-ui-adjustments.mjs
node frontend/tools/verify-account-fit.mjs
node frontend/tools/verify-typography-login.mjs
```

Vite 以 frontend 为根时，浏览器 `/src/...` 模块地址仍成立，不加 `/frontend` 前缀。构建输出 frontend/dist，Blender 从仓库根导出到 frontend/public/assets。工具写根 docs/output 不依赖终端 cwd。

## 3. API、会话与数据边界

开发：浏览器 → Vite 5173 → `/api` 代理 → Spring Boot 8080 → 数据库。`API_PROXY_TARGET` 默认为 `http://127.0.0.1:8080`；本轮仅预留代理，应用未发认证请求。部署时前端静态资源和 `/api` 后端通过同一站点反向代理，两端仍独立构建。

建议 Spring Security 服务端会话 + HttpOnly Cookie，HTTPS 使用 Secure，SameSite 按同站部署设置；保留 CSRF，前端取得 token 并在修改请求携带，登录/退出后更新。API 返回 JSON 401/403，不重定向为 HTML。后端负责密码哈希、登录限流、用户隔离；密码不写浏览器存储或日志。真正30天免登录用服务端持久登录凭证及撤销策略，现有 LoginMemory 仅记用户名。普通会话先按单实例设计，跨重启会话是否引入 Spring Session JDBC 在后端阶段确认。

| 首批接口 | 职责 |
|---|---|
| GET /api/v1/auth/csrf | 获取 CSRF token |
| POST /api/v1/auth/register | 校验并创建用户，保存密码哈希 |
| POST /api/v1/auth/login | 会话登录，可选择持久登录 |
| POST /api/v1/auth/logout | 撤销会话和持久登录凭证/Cookie |
| GET /api/v1/auth/session | 恢复当前身份 |
| GET/PATCH /api/v1/me | 当前用户资料 |
| GET /api/v1/me/favorites | 当前用户收藏 |
| PUT/DELETE /api/v1/me/favorites/{poemId} | 幂等收藏/取消 |

新增 api/http 与 AuthStore，把身份恢复/游客/已登录/失效分开。LibraryStore 保留游客资料；账号数据按后端认证身份读取，不采信客户端 userId。游客仍可浏览诗文与场景，登录后主动选择导入本机收藏，不能自动绑定公共电脑资料。退出/切换账号清账号缓存，恢复独立游客数据。

头像云保存是后续独立上传操作，明确提示并重复校验格式/大小/权限，文件存 runtime 或对象存储，不进 backend/src 或 frontend/public。诗文、场景与动画继续前端管理；收藏使用稳定 poemId，后端 ID 校验来源在接口契约中明确。

现有注册没有验证邮箱，邮件恢复需先选择邮箱验证或其他恢复方式；生日/性别可选，协议正文和接受版本需要落实。数据库建议 MySQL；仍可在创建后端前改选 PostgreSQL，本轮未初始化数据库。

## 4. Spring Boot 创建配置

2026-10-02 已核对 [Spring Initializr](https://start.spring.io/) 实时元数据与 [官方系统要求](https://docs.spring.io/spring-boot/system-requirements.html)：稳定默认项为4.1.1，Java21可选，官方兼容Java17–26。

| 字段 | 推荐值 |
|---|---|
| 保存目录 | 根 backend，不形成 backend/backend |
| Project / Language | Maven / Java |
| Spring Boot | **4.1.1**，不用 Snapshot/Milestone |
| JDK / Project SDK / Maven运行JDK | **21**，该系列当前维护补丁 |
| Java language level / pom java.version | **21**，不启用 preview |
| Packaging / 配置格式 | Jar / YAML |
| Group / Package name | com.poeticrealm |
| Artifact / Name | poetic-realm-backend |

JDK 是工具和运行环境，Java语言级别是编译目标，两者统一21。使用生成的 Maven Wrapper 与 Boot 依赖管理，不单独指定 Spring Framework/Security/Hibernate 版本。官方启动类/包布局参考：[Structuring Your Code](https://docs.spring.io/spring-boot/reference/using/structuring-your-code.html)。

勾选 **Spring Web、Spring Security、Validation、Spring Data JPA、MySQL Driver、Flyway Migration**；可选 Actuator（限制端点）、DevTools（仅开发）。改PostgreSQL时换对应驱动。核对生成pom包含数据库的Flyway模块，MySQL对应flyway-mysql。Remember-Me及CSRF见 [持久登录](https://docs.spring.io/spring-security/reference/servlet/authentication/rememberme.html)、[CSRF](https://docs.spring.io/spring-security/reference/servlet/exploits/csrf.html)。

```yaml
# 后端创建后的示例；本文件不是已部署配置
server:
  port: 8080
  servlet:
    session:
      timeout: 30m
      cookie:
        http-only: true
        same-site: lax
        secure: ${COOKIE_SECURE:false} # 仅本地HTTP；正式HTTPS必须true
spring:
  application:
    name: poetic-realm-backend
  datasource:
    url: ${DB_URL}
    username: ${DB_USERNAME}
    password: ${DB_PASSWORD}
  jpa:
    open-in-view: false
    hibernate:
      ddl-auto: validate
  flyway:
    enabled: true
  servlet:
    multipart:
      max-file-size: 5MB
      max-request-size: 6MB
app:
  auth:
    remember-me-validity: 30d
    remember-me-key: ${REMEMBER_ME_KEY}
  media:
    directory: ${MEDIA_DIRECTORY}
```

app.* 是后续自定义 ConfigurationProperties，不能自动实现认证。数据库凭据、REMEMBER_ME_KEY、MEDIA_DIRECTORY 通过环境或忽略的 application-local.yml 提供；profile 用 SPRING_PROFILES_ACTIVE=dev。本地配置如需启用应显式加载local profile；后端不自动加载前端.env。数据库由 Flyway 建表，ddl-auto使用validate，不用update改正式库；首次启动前提供数据库与迁移。
