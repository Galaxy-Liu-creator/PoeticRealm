# 生成提示词 · v01

> 用户认可现有 Desktop 风格后，按反馈修正等尺寸卡片，并继续扩展页面与转场。最新范围仅桌面网页，S07–S09 的历史提示词不再执行。下列小节是基础 brief；精确实际输入以 `v01`–`v06` 的 `screens/`、`transitions/` 下各 `request.json` 为准。调用成功、失败及实际尺寸见 generation-log.md 与各版 manifest；存在请求文件不代表已生成。
> 用法：将“通用约束”与目标画板的小节一起提交给 Stitch 或 GPT-image；保持同一项目 / 参考图体系。实际模型、参数、任务 id 写到 generation-log.md。
> 用户审批前只产设计稿，不将生成 HTML / CSS 接入应用。

## 通用约束

```text
为中文交互式诗词山水网站《诗境·一卷山河》制作高保真 UI 设计稿，不是代码实现。
气质：东方山水构图、写实自然材质与光照、克制的书法界面。中国文化来自山川、诗词、唐风建筑与留白，不来自宫廷装饰。
画面必须像可实现的浏览器作品设计，而不是游戏海报、设备模型展示或只有风景没有 UI 的壁纸。
正文与按钮均为简体中文。品牌标题精确写作“诗境·一卷山河”，标题有行书笔意，其余操作文字清楚易读。诗句竖排、从右向左排列各列；左上定位不改变阅读顺序。
禁止：纯黑或纯白首页、霓虹流光、仙侠传送门、龙凤祥云、宫廷金红、明清彩画、玻璃拟态、发光大按钮、游戏 HUD、积分等级、收费订阅、英文填充文案、乱码、假用户数。
正式收录范围只有三首：《枫桥夜泊》唐·张继、《江雪》唐·柳宗元、《早发白帝城》唐·李白。不要编造额外诗词填满网格。
首页无返回，非首页有返回；全站导航为“诗词总览 / 我的收藏 / 个人中心”。诗境另有“收藏本诗”状态控件。
动效用静态构图表达其层次，另做分镜板，不假称静图证明动态已实现。
只使用虚拟资料，不使用真人照片或其他产品的商标。不要给本项目设计登录付费墙。
输出干净画板，不加浏览器外壳或手机外壳。先出一张，不自动替换已经审批的设计。
```

## S01 · 首页桌面（第一张，优先生成）

```text
桌面画板建议 1440×1000。
顶部是轻巧而清楚的网站导航：左侧小型品牌字标，右侧“诗词总览 / 我的收藏 / 个人中心”，首页不要返回按钮。
导航下方约 300px 高的深青黛山水题头：层叠山峰在薄雾中退远，前方江水有细腻反光与流动的水纹。正中或略偏左大幅行书“诗境·一卷山河”，留足呼吸感，副文案“循诗入境，展卷见山河”。题头不要占满整个首屏。
题头以下另一个明显较亮的青灰、淡绢色山水背景区域，有浅远山、雾带与水光，不是纯白纸、不只是渐变色块。区域名“诗词总览”。这里必须仍能感受到中国山水的自然动态方向。
显示三张大而精致、轻微高低错落、具有悬浮阴影的诗词卡片，围绕稳定三列网格排布，不相互遮挡。三卡同时出现在首屏主体内。
卡一：蓝灰夜江、唐风寺远影、真实木舟与暖渔火；诗名“枫桥夜泊”、作者“唐·张继”，代表句“江枫渔火对愁眠”。
卡二：银灰雪山、冷青江水、一叶孤舟与细雪；诗名“江雪”、作者“唐·柳宗元”，代表句“独钓寒江雪”。
卡三：青绿峡谷、晨霞、轻舟；诗名“早发白帝城”、作者“唐·李白”，代表句“轻舟已过万重山”。
每张有低调的收藏书签和明确的“入境”指示。收藏不做巨大心形，不做商城价格、排行榜或数字统计。
文字清楚，边框克制，画面素材有真实质感。让上方深色题头与下方较亮卡片区既分明又统一。
```

## S02 · 枫桥诗境桌面

```text
沿用 S01 的导航与字体系统。1440×1000 诗境展示页。
主画面为可信的三维江南夜景：前景有湿润石岸与真实木舟，中景江面细波与局部渔火反射，侧方枫树，远处唐风寺和钟楼在薄雾中。深出檐、缓屋坡、结构可信，不用夸张明清飞檐或金色宫殿。
空间有前中远层次，蓝灰夜色保留暗部细节，渔火只占少量暖色，不整个场景黑成剪影。不要低多边形灰模或整幅油画滤镜。
左上留清楚而轻盈的竖排诗文安全区，右起各列：月落乌啼霜满天 / 江枫渔火对愁眠 / 姑苏城外寒山寺 / 夜半钟声到客船。另写诗名与唐·张继。
顶部有“返回”、全站导航、“收藏本诗”与静音状态。小型“译文 / 注释”入口即可，不用大侧栏、播放进度 HUD 或游戏控制器。
这是入场完成后的安静画面，不要把火烧转场永久留在场景里。主要画面仍是诗境而非卡片容器。
```

## S03 · 江雪诗境桌面

```text
1440×1000，沿用同一站点导航。
真实材质的冬日江面、雾中层叠雪山和一叶孤舟，蓑笠翁与钓竿细小但可辨，孤舟位于中下偏右。留白由浅雾和低对比山水空间形成，不是纯白空图。
从右上向左下落细碎雪，宽广分布、近远尺度不同，当前是安静持续雪势而非转场暴雪。水有细微动态质感，木舟与蓑衣不是剪纸轮廓。
左上竖排原文，右起各列：千山鸟飞绝 / 万径人踪灭 / 孤舟蓑笠翁 / 独钓寒江雪。诗名“江雪”，作者“唐·柳宗元”。字在雪景里有足够对比，不挡孤舟。
顶部有返回、我的收藏、个人中心和收藏本诗。无游戏 UI、无全屏白光、无大玻璃面板。
```

## S04 · 白帝城诗境桌面

```text
1440×1000，全屏可探索三维峡谷的设计：巨大但可信的青绿岩壁、前方江流与轻舟、远处山脊上的唐风城轮廓、被晨光染暖的云带。
岩石有自然层理与粗糙度，江流有方向感，山体不是尖锥拼块。光照不超现实，不用悬浮仙山、龙或宫廷楼阁。
诗文放在左上或另一块不遮主要峭壁和轻舟的留白区域，竖排右起：朝辞白帝彩云间 / 千里江陵一日还 / 两岸猿声啼不住 / 轻舟已过万重山。
展示“早发白帝城 / 唐·李白”。沿用导航，提供返回、收藏本诗、声音开关。画面表达舒展与自由，视平线稳定。
```

## S05 · 我的收藏

```text
1440×1000。沿用首页的较亮青灰绢色动态山水背景和卡片系统，顶部有返回与站点导航，“我的收藏”为当前项。
页面标题“我的收藏”，文案“一念留存，再入诗境”。虚拟状态下收藏了枫桥夜泊和江雪，展示两张真实对应的卡片与已收藏书签，不添加假数量和等级。
卡片可进入诗境，单独提供“取消收藏”；留白自然，不因为只有两张就虚构更多内容。
收藏空态另在 S10 状态板展示，不与当前有收藏状态混在一张画面里。
```

## S06 · 个人中心

```text
1440×1000。青灰山水低对比背景，清楚的非玻璃内容区域，顶部有返回、诗词总览、我的收藏、个人中心。
标题“个人中心”。左侧或上方为原创山水纹样默认头像，旁边有“选择本地图片 / 恢复默认”，下方提示“JPEG、PNG、WebP，最大 5 MiB”。
资料表单：姓名“山水客”，性别当前“未设置”，可选未设置、女、男、自定义。明确字段 label、保存和取消。表单不是古文谜语按钮，要易读易用。
明显但不突兀的说明：“仅保存在此浏览器，不上传云端。”没有注册、密码、邮箱验证或社交关注。
下半区“我的收藏”，展示枫桥与江雪的缩略诗卡并能进入，附“查看全部”。静态示意资料不能是真人身份或照片。
同时留出保存成功 / 失败反馈的位置；头像裁切弹层另放状态板，不盖住整张主稿。
```

## S10 · 关键状态板

```text
输出清楚标注的状态板（不是新增业务页面）：
1. 空收藏：“尚未收藏诗词”与“去总览选诗”。
2. 进入诗境加载失败：仍保留来源总览，显示“暂时无法进入 / 重试 / 取消”，不烧出黑屏。
3. 头像损坏或过大：中文错误和重新选择，旧头像保留。
4. 本机存储不可用：“本次修改仅在当前会话保留”，不显示“已永久保存”。
5. 头像裁切预览：确认与取消。
6. 减少动态效果：页面和导航相同，卡片与背景停稳，转场替换为短淡入淡出。
颜色与字体延续已批准页面，不用系统弹窗截图或红色报警大面板。
```

## T01 · 中央火烧揭幕分镜

```text
输出一张横向五帧概念分镜板，标明 0% / 25% / 50% / 75% / 100%，来源是 S01 总览，目标是 S02 枫桥。
0：完整首页；25：中央一个小而不规则的燃烧开口，里面已经可见蓝灰夜江；50：开口扩展，薄焦边、暗橙火缘、极少余烬；75：只留外围来源纸面，枫桥主体清楚；100：干净枫桥诗境，转场火焰全部退去。
必须表达“烧开旧页面露出新诗境”，不是寺庙火灾，不是爆炸或传送门，不全屏炫光。不同帧保持同样构图，不画成五个不相干的风景。
```

## T02 · 右上广域碎雪分镜

```text

每帧维持清楚的雪向与来源目标交接；雪是细碎广域雪，不是几个大雪花图标，也不是五张纯白渐变。
```

## T04 · 翻书返回分镜

```text
五帧从 S02 诗境返回 S01 总览，0% / 25% / 50% / 75% / 100%。
诗境画面成为纸页正面，从左向右翻起；中间帧清楚看到纸页卷曲、正面图像、浅绢色背面、柔和投影和下方已就绪的总览。不是整个窗口平移、旋转木板或立方体切换。
100% 恢复完整总览与原卡片，首页无返回。分镜需要标明诗文和顶部导航如何与纸页同步淡出，避免转场结束后文字悬在旧位置。
```

## 生成后自检

逐字检查标题 / 诗句；核对首页无返回、非首页有返回；三诗身份准确；模型与建筑没有幻觉结构；图里没有游戏化 UI。记录缺陷并提交修订，不悄悄把原图覆盖掉。不得将“任务已发出”写成“出图已完成”。
