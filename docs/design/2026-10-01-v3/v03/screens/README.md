# v03 扩展首稿与等尺寸卡片

v03 在用户认可现有 Desktop 风格后扩展，同一 Stitch 私有项目生成。这里保留首稿，不覆盖后续修订。

- S01 三卡已等尺寸；[浏览器测量](../card-measurements.json) 记录 1440px 视口下约 405.3×520px、封面高 340px。七字预览排版仍需纠错，最终推荐版本以 [设计入口](../../../README.md) 为准。
- S02–S06 是三首诗境、收藏和个人中心首稿，已经目视检查，排版与多余文案修订另存 v04/v05。
- S09 是移动江雪首稿；S10 是六类异常/空态/裁切/减少动态的状态板，后者为审批材料，不是新增业务页面。
- `S01-home-desktop-final`、S07、S08 请求连接失败，没有可核验本地图片；[失败记录](../stitch-failures.json) 单独列出，远端是否完成未知。

每个成功稿保留 PNG、精确 request.json 和 `../sources/` 的原始 Stitch HTML。模型、资源名、画板 id、实际图像尺寸和哈希见 [manifest](../stitch-manifest.json)。不修改图片像素，也不将源稿接入应用。
