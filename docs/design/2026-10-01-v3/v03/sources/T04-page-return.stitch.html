物理材质与翻折网格规则

宣纸骨力与网格形变： 严禁生硬平面左右平移或机械立方体翻滚。采用 32×32 柔性顶点位移网格 (Deformation Mesh)，依据中国生宣纤维韧度计算受力曲线，表现真实古籍翻折的挺括与垂落。

无障碍与平稳降级策略
