# v03 转场首稿 · 保留对照

同一 Stitch 项目生成四张五帧分镜：火烧揭幕、碎雪覆幕、云水入峡、翻书返回。原始 PNG 与实际请求均保留，画板 id、会话 id、尺寸及 SHA-256 见 [manifest](../stitch-manifest.json)。

首稿自检发现：火烧 25% 开口为空白、50% 更像角部掀纸；翻书中间帧对纸背和曲面表达不足；来源总览被简化为文字方块。工具还自动加入未经验证的显存、FPS、WCAG“通过”、音频数值及批准按钮。这些内容不构成事实、验收结果、用户批准或工程约束。

已经据此提交 v04 局部修订，推荐稿以 [设计入口](../../../README.md) 为准。旧板只作对照，不将自动扩充文案接入产品，也不以静态分镜宣称动画已完成。
