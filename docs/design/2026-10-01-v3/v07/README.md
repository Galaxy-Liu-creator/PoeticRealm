## 冻结的设计契约

- 目标：从总览选诗、在个人中心查看自己的资料与诗词；从独立幕布入口选择登录或注册。新图优先于被替代的历史提案。
- 视觉：青黛山水、温润绢纸、留白处书法。品牌标题行书，诗文与表单采用清楚的中文衬线字形；正式字体许可实施时核验。
- 总览：上区风景背景直达视口两边，内容保留内边距；下区另用幽深竹林、层叠雾山、隐约楼阁与江水，不复用题头背景，不用空白色块代替。
- 三卡：外框、封面、内容区等宽等高；顶部、底部、封面分界、诗题、代表句与按钮分别对齐。取消中卡抬高和分卡相位错落。若保留悬浮，只允许三卡同步同幅位移；悬停或聚焦任一卡时整组停稳。
- 白帝城：右起依次为“朝辞白帝彩云间 / 千里江陵一日还 / 两岸猿声啼不住 / 轻舟已过万重山”，各七字，四列等宽、列间距相同，顶部与底部一致。沿用枫桥的排版节奏，不换晨峡场景。
- 个人中心：完全以 S06 用户图为布局基准：全宽深青题头；下区左栏人物头像、昵称、资料卡，右栏收藏、最近浏览、成就与偏好、系统设置。圆形头像、轻纸纹、小圆角细边、低对比山影遵循原图。不要沿用旧 Stitch 资料大表单布局。
- 登录 / 注册：同一全屏山水与侧幕背景，左侧品牌、宣传语及四项体验，右侧绢纸表单；字段、行距、尺寸比例、图标位置、按钮和角纹以两张用户原图为准。登录含用户名/邮箱、密码、记住我、忘记密码、切换注册；注册含用户名、密码、确认密码、生日、性别、协议选择与切换登录。
- 间距与密度：按参考图比例建立桌面栅格；适配 1440 和 1920 桌面宽度，缩小窗口时允许纵向滚动，不压缩表单到难以阅读；不新增移动设计稿。
- 无障碍：表单标签与控件关联、可见键盘焦点、图标按钮有名称、输入错误可读；装饰不接收点击，拉幕后焦点落到目标页标题或首个输入。
- 装饰选择：山水、纸纹、头像边框与幕布金线来自用户指定中国风；保留其视觉作用，不扩充光晕、粒子、渐变字或新的徽章。参考中的 12/28/36、3/12、历史时间及邮箱是示例，实际界面使用真实数据，不因还原图片而伪造用户数据或解锁成就。
- 最有辨识度的特征：覆盖全屏的青黛织纹舞台幕布向两侧拉开，露出同一山水世界内的登录或注册表单。
