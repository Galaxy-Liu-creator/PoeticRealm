# T05 · 登录 / 注册舞台拉幕规范

**历史设计规范。** R1 已实现 DOM 拉幕首版，完整布面与场景全局时钟整合仍待后续，见 [R1报告](../../../plans/R1-UI还原/report.md)。下面保留原提案；S13 仍有效，登录/注册已由 v10 替代。原来源：[S13](references/S13-curtain-entry-user.png)、[S11](references/S11-login-user.png)、[S12](references/S12-register-user.png)。

## 入口与目标

`#/account`（拟议）显示全屏闭合青黛织纹双幅幕布，中央“诗境·一卷山河”，下方“循诗入境，展卷见山河”，再下方“登录 / 注册”。点击登录目标为 `#/login`，点击注册目标为 `#/register`。拉幕是账号入口流程，不覆盖每次进入总览；网站默认总览入口保留。

登录与注册底层目标先完成背景、字体、表单首屏准备，仍被幕布完整遮住。只有目标就绪才开始揭幕；加载失败保留入口与可重试反馈，不露空白、不播放无限幕布动画。直接访问登录/注册链接可直接显示目标表单，返回账号入口再恢复闭幕。

## 拉幕时序

建议首轮 1.2 秒作为动态小样起点，最终以实际浏览器视频确认。归一化 `p∈[0,1]`，固定进度可重复截帧，不用墙上时间驱动画面。

| 进度 | 画面 | 交互 / 验收 |
|---|---|---|
| 0% | 全幅闭幕、宣传语与两按钮；目标页已准备在下面 | 接收一次选择；目标未就绪不提前隐藏按钮 |
| 25% | 宣传语与按钮柔和淡出；中央接缝分开，两边褶皱同时向外收拢 | 左右相同节奏与缓动；中缝先露出真实目标山水 |
| 50% | 两幅幕布外移，山水和对应绢纸表单逐步露出；金线/穗饰随各自幕幅移动 | 同一张目标页从始至终在幕下；禁止中途换图、黑帧、闪白 |
| 75% | 幕布收至两侧；表单已清楚，帘缘保留柔和阴影 | 不让正文或按钮独立漂移；原参考图侧幕成为完成态构图 |
| 100% | 登录或注册页完整呈现，侧边保留原图装饰幕，中央遮盖层移除 | 输入解锁、路由确认、焦点移到目标标题/首个输入；无幕层拦截点击 |

主运动采用同一 `cubic-bezier(0.65, 0, 0.35, 1)`，缓起缓停，不弹跳。标题/按钮淡出控制在前 0.18–0.24 秒。两幅幕布用独立裁切素材或分层布面，向左右滑动并轻度横向收拢，保留褶皱与垂坠；不能直接把含宣传语和按钮的整张截图切两半滑走。

## 实施约束

- 使用现有 TypeScript + GSAP 体系，时间线暂停后由全局时钟 seek。动画进度、位移与透明度是 `f(p)`，不新增持续 RAF/计时循环。
- 位移与透明度优先使用合成属性；不逐帧修改宽高、布局间距或高强度模糊。幕布层只在转场时存在，完成/取消后释放临时图层和监听。
- 重复点击只采用首次有效目标；浏览器后退/取消时取消未完成目标准备并恢复来源状态，之后仍可再选登录或注册。
- 登录/注册页内部切换保留共同山水，建议 180–240ms 短过渡；不每次重演整场拉幕。
- `prefers-reduced-motion: reduce` 直接切换到对应完整表单，不执行双幅位移、缩放和渐变动画；焦点与路由语义相同。
- 标签页隐藏时暂停并保存全局进度，恢复时连续推进，不能跳回闭幕或重复执行提交。
