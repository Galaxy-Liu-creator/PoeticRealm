# v08 · 总览背景减法修订

用户最新反馈：v07 下区山河、色彩与细节过多，产生审美疲劳；保留角落竹叶，中间改成更简单的云雾。本轮仍只改设计稿，不改运行代码。

**[首页修订图](screens/S01-home-desktop.png)** · [完整提示词](requests/S01-home-desktop.prompt.txt) · [文件与来源校验](manifest.json)

## 本次设计约束

- 上区保持全宽青黛山水、行书品牌与现有导航。
- 下区改为浅灰绿 / 米绢色、低对比云雾，中央不再出现山体、河流、楼阁、河岸或水面倒影；色彩收敛，留出安静空间。
- 竹叶只在角落少量点缀，不沿两侧铺成连续密集边框，不遮文字与卡片。
- 三张卡片继续等高、上下齐平，保留各自诗境封面、诗名、作者、代表句、收藏和入境；卡片内部的山水画面不属于本次背景删减范围。
- 沿用现有书法、绢纸与国风元素，不增加光晕、粒子、渐变字或新装饰。

## 来源与审批边界

内置 image_gen 以 v07 最终 S01 PNG 为编辑目标，另存 v08，不覆盖旧稿。工具未提供模型名或服务任务 id，不猜测，不标为 Stitch 导出。个人中心、白帝城、登录注册与拉幕规范仍沿用 v07。

新稿待用户复审。目视检查用于确认背景简化、角落竹叶、诗文及控件保留；PNG 尺寸、字节数与 SHA-256 按 manifest 实测。静态图片编辑可能重新采样，不能证明精确 CSS 尺寸、实时动态或浏览器交互；本轮不运行应用构建与动态验收。
