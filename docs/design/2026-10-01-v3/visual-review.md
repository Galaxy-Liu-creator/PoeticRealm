# 扩展稿自检 · 非用户审批

## 对齐原始要求

| 要求 | 设计表达 | 实施时仍需验证 |
|---|---|---|
| 直接进入诗词总览、双背景区域、行书题字 | S01 深青黛题头、浅绢色山水卡片区；三首诗同规格 | 山水、水光实际流动；首屏和缩放适配 |
| 意象决定入场方式 | T01 中央火烧、T02 右上广域碎雪、T03 云水 | 连续遮罩、预加载、转场中断和减少动态模式 |
| 诗文与写实诗境 | S02–S04 左上诗文安全区，夜江、寒江、晨峡各有主题 | Blender 建筑/木舟材质；Three.js + GLSL 自然环境；图片不是已完成模型 |
| 返回、收藏、个人中心 | 总览无返回，其余有返回；诗境收藏本诗；T04 翻书返回 | 路由、焦点和原总览滚动位置恢复 |
| 本地头像、姓名、性别和收藏 | S06 桌面表单与收藏；S10 错误及裁切状态 | 上传校验、裁切、存储失败与资料持久化 |
| 先生成供审批、按原形式保存 | 同一 Stitch 私有项目；逐版 PNG / request.json / 原始 HTML / manifest | 用户逐稿审批后才进入前端实施 |
