## 关口

- 首页有两个分区，顶端行书题字准确、背景非纯黑白、山水动态可辨。
- 诗境主画面真实、有质感；导航、诗句、收藏不遮主体。
- 雪 / 火 / 翻页的来源目标与遮罩逻辑能从分镜理解。
- 个人中心包含本地头像、姓名、可选性别和收藏；本机模式明确为待审批默认方案。
- 用户明确批准相应图稿后才做实现；“文档写完”不等于“设计通过”。
