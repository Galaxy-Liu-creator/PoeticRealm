# R1 · 桌面 UI 首版报告

2026-10-01。用户要求先核对 docs 是否符合新 UI，再修文档并开始实现。已同步设计入口、目录映射、页面地图、路线图、验收和 README；设计历史及用户已有未提交变更保留，未提交或推送。

## 实际实现

- 默认总览、收藏、个人中心、三首诗文预览、账号入口、登录与注册，共九个页面；hash 深链接、无效页与浏览器历史。显式 scene/debug/t/q 查询参数继续进入 src/legacy.ts 的旧 P0。
- 总览三卡等高齐平；选用 v09 无文字封面和画面区域，导航、标题、原诗、书签和按钮使用 DOM。保持青黛、绢纸、竹叶与山影，不将整页设计图铺成可点击页面。
- 收藏、资料、256px 头像、最近浏览与偏好使用带版本的 localStorage；刷新恢复、跨窗口数据更新、失败时会话保留和明确提示。用户文本转义；头像检查格式、头部、大小、像素与解码，本地中心裁切缩放并重采样，不上传。
- 个人中心使用真实本机数量；通知与推荐禁用并说明暂未开放。深色模式和动态开关可用。
- 账号页有输入验证和密码显隐；服务待用户决策，提交明确说明未接入，不保存密码或伪造成功，没有接入数据库、邮箱或云同步。
- 拉幕先解码目标画面，双幅无文字侧幕同时外移；文案 220ms 淡出，主运动 1200ms 缓起缓停；输入锁定、结束焦点、后退取消、等待图片时取消、失败恢复与重试。隐藏标签页暂停 Animation，减少动态跳过运动。

## 剩余差异与边界

这是可操作的 UI 首版，尚非逐像素最终复原：标题使用本机行楷回退；部分纸纹、云纹、穗饰与账号完整无文字山水底图需独立分层资产，当前以局部画面和 CSS 复现主构图。画面引用的原始 PNG 较大，生产构建图片合计约 14.4 MB，未宣称冷缓存首屏 ≤3 秒；后续应提取并压缩单独区域、子集化授权字体。

三诗页仍是明确标注的静态预览，没有假装为实时 Three.js 场景；火/雪/云水/翻页、声音、PBR 与目标机帧率仍在 R2/R3/R4。R1 Animation 的进度可定位，最终 GSAP / 场景全局时钟整合及布面物理收拢另验。账号选择由用户决策，不以本机数据充当账号。

预览图来源与发布限制见 [CREDITS](../../CREDITS.md)。Vite 将所引用的设计原图打入 dist，当前构建仅本地预览；未部署，正式对外发布前需核实许可与比赛声明。
