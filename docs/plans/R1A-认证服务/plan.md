## 阶段与成功标准

1. **目录与文档**：前端迁frontend，运行素材独立于docs，修工具/制作输出路径，清理重复进度入口。构建、全部单测、四套浏览器脚本、P0查询回归通过；用户已有修改保留。
2. **后端认证**：Boot4.1.1/JDK21/Java21/Maven；数据库迁移、密码哈希、会话/CSRF、退出和持久登录。验证合法/非法注册、重复用户名、密码失败和撤销。
3. **前端接入**：api模块、AuthStore、表单实际提交与身份恢复，错误/失效反馈；保持游客浏览和已有页面布局。
4. **本机资料隔离**：按服务端返回的账号ID选择独立本机库；游客与不同账号的资料、收藏、头像和足迹不自动混入，退出恢复游客资料。
5. **认证首版验收**：后端集成测试、真实浏览器闭环、隔离数据库的空库迁移与既有版本校验；本机 MySQL 配置后补实库联调。
6. **后续账号云数据**：独立任务实现云端资料、收藏、明确的游客导入、头像上传及浏览同步；需要服务端权限、并发重复收藏和失败恢复验证。

本轮不建立外部数据库、邮件服务或部署；H2仅用于隔离测试。现有注册无邮箱，恢复方式另行确定。API、Cookie及数据隔离按 [架构规划](../../architecture/前后端分离与认证规划.md) 与 [认证接口](../../api/认证接口.md) 实施，未成功的请求不得显示认证成功。
