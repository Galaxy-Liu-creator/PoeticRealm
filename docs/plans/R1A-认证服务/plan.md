# R1A · 前后端分离与认证服务

2026-10-02。用户选择Spring Boot。当前先执行文档整理与前端迁移，后端由用户按 [创建配置](../../architecture/前后端分离与认证规划.md#4-spring-boot-创建配置) 创建。

## 阶段与成功标准

1. **目录与文档**：前端迁frontend，运行素材独立于docs，修工具/制作输出路径，清理重复进度入口。构建、全部单测、四套浏览器脚本、P0查询回归通过；用户已有修改保留。
2. **后端认证**：Boot4.1.1/JDK21/Java21/Maven；数据库迁移、密码哈希、会话/CSRF、退出和持久登录。验证合法/非法注册、重复用户名、密码失败和撤销。
3. **前端接入**：api模块、AuthStore、表单实际提交与身份恢复，错误/失效反馈；保持游客浏览和已有页面布局。
4. **账号数据**：资料/收藏及明确的游客导入，随后头像/浏览；验证越权、账号切换、并发重复收藏和失败恢复。
5. **验收**：后端集成测试、浏览器闭环、数据库迁移报告，之后进入R2。

本轮不创建数据库、邮件服务或部署。现有注册无邮箱，恢复方式在后端阶段确定；认证未接入时不存密码或伪造成功。API、Cookie及数据隔离按 [架构规划](../../architecture/前后端分离与认证规划.md) 实施。

当前进度与验证只写根HANDOFF；完成阶段写report，不把目标目录或配置示例当作已有后端。
