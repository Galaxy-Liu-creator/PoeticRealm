## 已实现行为

- 后端保留 Boot4.1.1 / Java21 / Maven / com.demo.backend，增加 auth/user/config/common。Flyway V1创建用户与持久登录表，JPA只校验结构。
- 注册校验用户名、密码复杂度、可选生日/性别与开发测试说明版本。用户名经NFKC与大小写归一化后唯一，密码使用BCrypt强度12哈希；注册成功后需主动登录。重复用户名409，其他数据库约束故障不伪装成重复用户名。
- Spring Security使用服务端会话，登录轮换会话ID与CSRF。CSRF接口返回屏蔽token，修改请求必须携带；当前用户接口按认证身份读取，匿名返回JSON 401，验证失败返回JSON 403。
- 记住我使用数据库持久凭证，30天有效期随使用更新，并轮换token。Cookie为HttpOnly、SameSite=Lax，HTTPS启用Secure；退出清理会话、Cookie并撤销该账号的持久凭证。普通会话超时30分钟、重启失效。
- 同一用户名15分钟内8次失败、同一来源IP30次失败后限流。来源使用直接连接地址，不接受任意X-Forwarded-For；成功登录清除用户名失败桶，IP窗口保留，避免通过成功登录绕过来源限流。
- 前端api/AuthStore实际调用接口，带Cookie与CSRF；仅CSRF拒绝时更新token重试一次。登录、退出不允许请求相互重叠，恢复响应不能覆盖较新的身份；明确401清账号身份，网络失败保留已知身份并标记服务不可用。
- 注册/登录提交期间禁用按钮、结束后清密码、失败准确反馈。个人中心显示真实账号并可退出；本机昵称、头像、收藏、偏好与足迹按游客或账号ID分别保存。游客数据不自动导入账号，退出恢复原游客库，首次诗词深链接等身份恢复后记录足迹。

接口、错误与边界见 [认证接口](../../api/认证接口.md)，配置与启动见 [backend/README](../../../backend/README.md)。
