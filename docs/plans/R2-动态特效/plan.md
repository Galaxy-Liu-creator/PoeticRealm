# R2 动态特效

2026-10-04 用户授权开始实施。视觉权威沿用设计文档与已选原稿，技术栈保持 TypeScript、WebGLRenderer、GLSL、Three.js 0.186.1。

## 本轮可交付

1. 首页单一氛围画布：慢雾、细水光，标题保持静止；卡片整组同相同幅浮动，悬停/焦点暂停。复用 Clock，隐藏/离屏取消 RAF，偏好关闭后静止。
2. 三个入境效果接真实 DOM：炭纸中央扩口（1.6s）、连续斜雪雾（2.1s）、顺江云水（1.5s）。先准备目标图片、字体和第一帧，再开幕；源页面保留，失败可重试/取消，快速点击只有一个事务。期间浏览器导航取消事务。当前目标仍是明确标注的静态预览。
3. 固定时间/进度调试接口、实际 Chrome DevTools 起止与中间帧、性能追踪、键盘/减少动态/取消/资源生命周期验证，完成后写 report 与 HANDOFF。

## 技术决定

使用 DOM 目标层与透明 GLSL 效果层配合：炭纸用同一数学轮廓驱动 DOM clip-path 与火缘；雪雾/云水在全覆盖时置换。没有截图 DOM 为纹理的成本和跨域字体风险；现有侧幕不改。回程真实曲面需另做 DOM/画布合成小样，不能拿平面滑动替代。

## 后续仍需完成

枫桥真实 GLB 质量、材料/光照/水体/薄雾/铃声闭环；曲面翻页返回及焦点恢复；江雪、白帝城缺失的模型/机位/环境音；最终三场景固定时刻和目标硬件性能。这些不由本轮入境预览冒充验收。资产接口改变前必须按 CONTRACT 同步验证器与导出。
