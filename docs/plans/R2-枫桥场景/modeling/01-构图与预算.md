# 01 · 构图与资产预算

[返回建模目录](README.md) · 下一篇：[组件与装配](02-组件与装配.md)

## 先确定空间关系

首轮布置一座主殿、一座钟楼、少量院墙、一座石拱桥及近岸；复用现有木舟校准米制尺度。河流转折、桥寺位置、前景枫树和远山共同决定画面层次。尺寸块是比例检查工序，之后由精修组件替换。

- 前景：湿石、水线、枫树枝叶、芦苇及近景舟。
- 中景：石桥、少量渔舟和暖渔火，倒影参与构图。
- 远景：寺院与钟楼、远山和低对比薄雾。
- 固定左上诗文留白，竖排右起；前景枝叶不遮住主要文字、桥拱或客船。
- 明确水位和月落方向；舟体、岸石、桥台与水面有可信关系，基础延伸到水下或岸坡内。

## 同时布置五组机位

| 机位 | 画面目的 |
|---|---|
| CAM_enter | 入境后的完整构图，能辨认江岸、舟火及桥寺层次 |
| CAM_moonset | 月落、冷江与远山，第一句的寒意 |
| CAM_riverbank | 湿石、江枫、木舟及渔火倒影 |
| CAM_temple | 穿雾见寺，檐线与钟楼可辨 |
| CAM_boat | 钟声到客船，稳定停留并看向寺院方向 |

相机和 FOCUS_ 来自 Blender，遵守 CONTRACT；镜头位置不散写在运行代码。先在 1920×1080、1440×900 检查构图，再增加细节；取景、焦点和诗文安全区一并检查。

## 预算先做压缩实验

先统计当前舟、人物、共享材质的分发字节和解码资源，再做去重与压缩对照，腾出寺桥和植被预算。当前资产及性能数据以 HANDOFF 为准。优化须保留骨骼、相机、挂点、PBR、UV、遮罩、舟壳封闭性和划桨约束。

| 分项 | 初步压缩目标 | 说明 |
|---|---|---|
| 舟与人物共享资产 | ≤5MB | 实验目标，需验证绑定、材质和近景质量 |
| 寺院、钟楼、桥 | ≤5MB | 共享材质、重复构件和静态空间块 |
| 岸石、枫树、芦苇 | ≤3MB | 少量原型、实例化、距离层级 |
| GLB余量 | 2MB | 全场合计仍遵守≤15MB |

以上是工作预算，不是已达成结果；组件或GLB拆分不改变全场统计。独立纹理、环境和音频另计总分发量与解码内存。贴图最大2K，优先共享1K；法线与粗糙度压缩必须检查数据和画质。

完整场景以≤300次多pass调用、≤700k多pass三角形作为工作目标，实际硬限制按 CONTRACT。性能基线为当前开发笔记本1920×1080/DPR1，三轮各60秒≥50fps、P95≤20ms；阴影、倒影和转场成本计入。答辩机确定后再复验。
