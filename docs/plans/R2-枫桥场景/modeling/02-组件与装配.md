# 02 · 组件划分与装配

[返回建模目录](README.md) · 上一篇：[构图与预算](01-构图与预算.md) · 下一篇：[建模与材质流程](03-建模与材质流程.md)

执行根 AGENT.md 的分段要求：每次制作一个组件或小组件组，独立检查后装配；总控脚本只组合已有组件。完整主体保留可编辑的源组件，发布版本可按契约合并或实例化。

## 各主体怎样拆分

| 主体 / 组件 | 建模方式 | 连接与检查 |
|---|---|---|
| 寺院：台基、踏步、柱础 | 分别制作石基轮廓、踏步厚度和柱础 | 柱础落在台基上，踏步接地，无漂浮或明显穿插 |
| 寺院：柱网、枋梁、斗栱 | 开间、进深、柱高、柱径共同参数化；可见承托结构做实体 | 柱承托梁架，斗栱与檐架接合；唐风比例先核查 |
| 寺院：椽架、檐口 | 制作可复用椽件，按间距排列，精修檐口和屋角 | 檐线、厚度和近景接合可辨，检查檐下阴影 |
| 寺院：屋面、瓦脊、墙门窗 | 曲面屋顶；檐口可见瓦片实体，远面烘焙细节；围护独立制作 | 屋面承接椽架，门窗落位；重复瓦件不各用独立贴图 |
| 钟楼：基座、柱梁、屋顶 | 复用寺院组件类型，按钟楼尺度组装 | 保持自身参数和结构，不直接缩放整个寺院 |
| 钟楼：钟架、钟体、悬挂件 | 钟剖面旋转生成内外壁、钟唇与悬挂位置 | 钟架真实承托；钟体厚度与悬挂关系保留 |
| 石桥：桥台、拱圈、拱石 | 拱轴线确定跨高，内外拱线之间挤出厚拱圈；分块拱石沿曲线排列 | 检查净空、石块承重方向和桥台入岸连接 |
| 石桥：侧墙、桥面、栏杆 | 桥面为缓坡实体，侧墙承接填筑，栏杆原型重复排列 | 正面、侧面、桥下与倒影检查，接缝微磨损烘焙 |
| 石岸：岸坡、水线、岩块 | 先做起伏岸坡和曲折水线；制作3–5个不同岩块原型 | 主石手动构图，根基延伸到水下；大裂缝保留几何 |
| 石岸：碎石、草苔 | 少量原型按固定种子散布 | 控制密度和尺度，检查重复、硬接缝和悬空根部 |
| 枫树：主干、主枝、次枝 | 曲线扫掠，枝径逐级收细；制作2–3种树姿 | 主枝方向人工构图，保留树冠空隙与可见江面 |
| 枫树：叶片、叶簇 | 少量有UV的枫叶原型，固定种子布叶 | 近处少量真实弯曲轮廓，其余共享叶簇与alphaTest |
| 芦苇：茎叶、穗、单簇 | 约3种株高、叶弯曲和穗姿，先单簇后散布 | 根部原点落地，按水线和坡度限制位置 |
| 现有木舟 | 保留连续船壳、肋梁、舷缘、篷、桨、人物与灯火挂件的组件边界 | 侧舷划桨和首尾封闭保持；局部修改后复验原约束 |

## 组件接口

- 尺寸和种子集中定义；组件之间用共同标高、轴线和间距推导位置。
- 单位、朝向、局部原点、缩放、名称及材质槽位遵守 CONTRACT。
- 连接点和父子关系明确，新增导出挂点或属性先走契约变更。
- 主体原型与重复实例分开；动态舟、桨、骨骼、植被及声光挂点保持独立。
- 远近精度按屏幕占比配置；植物单株近景≤3000、远景≤500三角形沿用现行契约，叶片和枝干都计入。

## 制作文件组织建议

以下为后续实现时创建的建议结构，不代表这些文件已经存在；允许按已验证工具链调整。

```text
art/
├── blender/
│   ├── components/fengqiao/        寺、桥、岸、植被制作库
│   │   ├── architecture-vNN.blend  独立台基、柱梁、椽檐、屋面组件集合
│   │   ├── bridge-vNN.blend        拱圈、桥台、桥面、栏杆组件集合
│   │   └── nature-vNN.blend        岩石、树干枝叶、芦苇原型集合
│   ├── fengqiao-scene-vNN.blend    组合已检查组件并登记镜头/挂点
│   └── fengqiao-sample-vNN.blend   保留既有小样修订
├── scripts/components/fengqiao/    分组件构建脚本与共同参数
└── textures/fengqiao/              原图、工作图及烘焙图
```

一个制作库可以容纳多个独立组件集合，仍须分段构建与检查。无需给每个小件单独发布一个GLB；运行资产按空间块、材质和动态语义组织。历史源、导出和验证证据不覆盖。
