# 04 · 自然动态、镜头与声音

[返回建模目录](README.md) · 上一篇：[建模与材质流程](03-建模与材质流程.md) · 下一篇：[实施与验收](05-实施与验收.md)

复杂主体由Blender交付；水、天空、雾、风与火在frontend/src/systems和shaders实现。场景文件只装配配置与分镜。保留锁定Three.js0.186.1、WebGLRenderer和GLSL；动画受全局时间t和固定seed驱动，支持暂停与固定时刻复现。

## 自然系统

| 元素 | 首轮实现 | 检查边界 |
|---|---|---|
| 江面 | 低振幅解析细波、细节法线和受控镜面倒影 | 水线与岸舟衔接；倒影与遮挡匹配，月火反光随波破碎 |
| 倒影 | 继续使用已选平面反射路线，寺桥舟轮廓与渔火参与 | 排除水面自身，透明层单独控制；统计二次渲染成本 |
| 湿石 | PBR粗糙度/法线、干湿过渡和环境受光 | 独立检查湿石反射；水面倒影不自动成为石面反射 |
| 月落与夜空 | 月亮独立天空元素，原创冷色夜空与环境亮度缓变 | 按t落向地平线，演出结束保持末态，月光方向与反光一致 |
| 薄雾 | 距离/高度雾，加少量局部低频雾片 | 留出舟桥寺层次；反射雾一致，透明重叠与排序可控 |
| 渔火 | 可见火形/发光层与实际暖光共享闪烁函数 | 火峰不过曝，暖光局部可读，发光材质不代替实际照明 |
| 船体 | 采样同一水函数求轻微升沉、俯仰与横摇 | 舟、桨、人物、灯和声源关系保持；系泊位置受约束 |
| 风与植被 | 共享风场，mask控制枝叶权重；稀少落叶按seed/t求位置 | 根部固定，深度/阴影形变一致，不每帧重新抽随机数 |
| 远山 | 复用高度图与受控远景轮廓 | 保留RG高度/B引导编码；近岸裂缝、悬挑由局部几何承担 |

静态原创预滤波环境、实时水倒影和投影阴影各有资源所有权。雾片、植物和反射参与对象按镜头距离控制；低档仍需保留关键意象。仿真如需积分则固定步长重建，不能让帧率决定状态。

## 四句演出

| 时间提案 | 镜头 | 声音与意象 |
|---|---|---|
| 0–8秒 | CAM_enter → CAM_moonset | 月落、冷江、远乌啼和低强度江风 |
| 8–16秒 | CAM_riverbank | 江枫、湿石、渔火与倒影；舟边水声 |
| 16–24秒 | CAM_temple | 薄雾中见寺和钟楼，为钟声留空间 |
| 24–32秒 | CAM_boat | 钟声抵达客船，末镜头稳定停留 |

时长沿用总计划和STORYBOARD，最终观看后校准。机位/焦点来自Blender，限制镜头速度和角速度，无滚转；结束后自然环境继续安静运行，演出不默认复位循环。

钟体位置对应SFX_bell，寺前江面波前起点对应EMIT_bell。到船时间按实际节点水平距离/340计算，布局变化时重新检查落在第四句窗口；可视化表示声传播意象，不把它当真实水波速度。声音已按抵达时间安排时不再次延迟。

声音解锁依赖入境按钮等用户手势；环境、音效、人声、音乐分轨。支持静音、暂停、seek、退出淡出与释放；跳转不补播全部跨过的瞬时声。拒绝解锁不阻挡画面与导航，声学距离和响度需实听。

## 真实三维转场

- 入境：资源与着色器准备 → 成功首帧 → 同一Canvas接现有火烧揭幕 → 成功提交导航并开始场景时间。
- 返回：冻结当前时间/机位 → 捕获当前三维帧 → 配合DOM诗文接翻页 → 成功后释放并恢复总览位置与焦点。
- 全部条带共享一次快照；不假定cloneNode复制Canvas内容。
- 取消、迟到加载、失败重试、后台暂停与减少动态遵守场景宿主生命周期，资源所有权不丢失。

接法与异常细节继续以总计划第7–8节和实际验证为准。

## D阶段落地顺序

从已检查的桥寺与近远层级源另存scene-v03，保留scene-v02源、发布资产和证据。按以下小段制作，每段通过相应检查后再进入下一段。

1. **机位与挂点。** 在Blender分件补CAM_moonset/FOCUS_moonset、钟声源与波前起点，核对四句机位/焦点、钟到舟的距离和导航遮挡；按正式CONTRACT补齐required nodes与RG高度/B引导图，并把新增分发资源计入预算。
2. **月与薄雾。** 自然系统置于systems与shaders，月落、月光方向和环境亮度用同一t求值；先实现距离/高度雾，再加入少量局部雾片。所有灯与物体动画先求值，再统一更新世界矩阵，随后由主相机选层，倒影、阴影和主画面共用。以0/8/16/24/32秒及结束后固定帧检查月火反光、雾中层次和末态。
3. **四句与三维宿主。** 场景只装配参数和演出；镜头来自上述制作机位，诗句右起竖排。先接暂停、seek和减少动态，再将成功首帧交给现有火烧入境；返回只捕获一次实际Canvas与诗文，供全部翻页条带共用。补取消、迟到加载、快速再进和焦点/总览恢复。
4. **声音与完整关口。** 江风、水声、乌啼、钟声按分轨加入；首轮原创合成原型需如实登记并实听，未通过不作为音色定稿。解锁失败不阻挡画面，seek不补播跨过的瞬时事件，静音、暂停和退出释放有独立检查。加入声音及演出后重测完整资产预算、实际演出与各近景开销、三轮持续性能和十次释放，再收敛目标机R4。

各机位短时开销诊断与完整持续性能报告分别保留；整体机位通过不推断所有近景或未来雾/音频负载通过。预算不足时先优化可复用远景数据与发布编码，不覆盖已选近景造型或直接降低倒影/阴影分辨率。
