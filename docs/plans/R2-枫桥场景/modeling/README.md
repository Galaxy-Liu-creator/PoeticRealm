# 枫桥 · 分段建模与动态制作规划

本目录细化 [R2 枫桥总计划](../plan.md)，用于完成寺院、钟楼、石桥、石岸、植被及夜景演出。先完成枫桥验收，再进入江雪与白帝城。参考研究日期为 2026-10-07；本文描述制作方案，实际完成情况和验证结果见根 [HANDOFF.md](../../../../HANDOFF.md)。

## 目录与阅读顺序

```text
docs/plans/R2-枫桥场景/
├── plan.md                         阶段目标、总体方案与接口迁移
├── modeling/
│   ├── README.md                   本目录入口、职责与阅读顺序
│   ├── 01-构图与预算.md            空间布局、镜头与资产预算
│   ├── 02-组件与装配.md            主体拆分、组件接口与组装关系
│   ├── 03-建模与材质流程.md        分段制作、高模烘焙与实时交接
│   ├── 04-自然动态与演出.md        水、雾、月、风、火、镜头和声音
│   ├── 05-实施与验收.md            制作批次、进入下一批的条件与证据
│   └── references.md               GitHub 研究、形制依据与许可边界
└── assets/                         各修订的真实验证证据，历史保留
```

建议阅读顺序：

1. [构图与预算](01-构图与预算.md)
2. [组件与装配](02-组件与装配.md)
3. [建模与材质流程](03-建模与材质流程.md)
4. [自然动态与演出](04-自然动态与演出.md)
5. [实施与验收](05-实施与验收.md)

制作具体组件前查看 [参考研究](references.md) 中对应的方法和边界。每个阶段先定义组件输入与输出，再分段制作、检查和装配；同类构件允许批量重复生成。
