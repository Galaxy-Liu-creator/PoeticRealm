# R3 · 江雪分段建模与浏览器交接

2026-10-10。用户已授权开始江雪建模；本轮按当前选定 S03 v04 原图制作冷青寒江、层叠雪山雪岸、孤舟和立姿蓑笠翁。属于艺术场景，不声明历史船型或服饰的精确复原。枫桥未完成的性能/冷启动与答辩机复验继续留在 HANDOFF，不据此重新生成或修改枫桥。

## 目标与边界

- 独立 `art/blender/jiangxue-scene-v01.blend`、可编辑源组件、GLB 候选和正式 RGB8 高度图；显式江雪 lab 检查真实 PBR、机位、水线、反射及释放。
- 视觉权威是 `docs/设计文档.md` 第9节与 S03 v04；银灰积雪、冷青江水，舟与人物置前景偏右，左上留诗文安全区。自然环境静，动作只做轻微舟摆；这一轮不扩展自动分镜或完整声音演出。
- 原生 TypeScript、Three 0.186.1、WebGLRenderer/GLSL、Blender5.1.1 保持；无付费生成、无新依赖。
- 每次执行只制作一个组件或明确的小组件组。装配只复制已检查产物，不生成隐藏几何。源/导出分开，原默认场景及枫桥十二项历史源/GLB SHA 保护。

## 组件与接口

水线为0m；舟沿局部+X，主体沿用已检查约6.6m舟壳；人物采用已登记CC0 hm08人体，站立高度约1.70m；钓竿长约3.2m、末端指向开放水域。尺度由实测舟壳和人体接触点确认后修订，不手填脱离源的船体尺寸。

| 顺序 | 组件 | 输入/连接 | 本段检查 |
|---|---|---|---|
| A | 独立场景、米制参数、CAM_/FOCUS_ | 16:9，Vertical，平远；关键主体居中4:3 | 无滚转、诗文留白、旧场景保留 |
| B1 | 舟壳与木构适配 | 原v04舟壳与木纹，独立复制 | 封闭性、法线、UV、船舱与水线 |
| B2 | 舟沿积雪 | 已检查舷缘，雪层厚度2–5cm | 真实厚度、不封死乘员舱 |

## 验收与证据

- 每段保存独立检查JSON与Blender检查点；主源只在当前修订更新，v01发布后后续另存v02。组件状态与真实结果只写根HANDOFF。
- 源、GLB、材质、人体许可与实际修改登记CREDITS；不下载或分发参考截图。
- 制作校验 → 统一export_glb → bake_terrain → 真实Node契约/预算 → Chrome DevTools MCP与Playwright。GLB总量≤15,000,000B，单图≤2048²；环境/高度图另报完整分发和解码内存。
- 固定机位/时间与连续视频检查，1920×1080和1440×900；无移动验收。1920/DPR1以至少50fps为目标，记录calls/多pass面数/P95，60秒三轮；加载缺失/取消、减少动态、十次释放不能随次数增长。
- 几何/材质候选通过只证明本轮模型交接；雪入境、诗文、安全区、声音与正常产品完整流程在后续运行接入时验收。
