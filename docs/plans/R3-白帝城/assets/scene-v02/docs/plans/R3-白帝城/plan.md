# R3 · 早发白帝城分段建模与浏览器交接

2026-10-21。用户在阅读项目约束、当前建模进度及白帝城实施建议后授权“行，开始做吧”。本阶段制作有限晨峡、可辨唐风城影与行江轻舟。当前进度和实际验证只写根 HANDOFF.md。

## 视觉与范围

依据设计文档第10、14–19节、STORYBOARD白帝城分镜及CONTRACT16.4。青绿植被、层叠灰岩、淡金粉晨霞、城台与江流构成高远/深远；舟在前景偏右，左上保留四列七字、右起竖排诗文。首版有限航线，机位无滚转。现有S04 v07的文字/manifest保留，当前Ubuntu未迁入完整PNG且原盘路径不可访问；制作使用已登记S04运行背景副本核对景物方向，完整稿恢复后复核，不另造审批原稿。

复杂几何由Blender制作，发布GLB；远山由独立米制规则地形烘焙1024² RGB8高度图（RG16高度、B引导）。水、晨光、云霞、雾和舟行由systems/shaders实现，scene只装配。复用锁定Three0.186.1、已有闭合舟壳、53骨骼船夫和PBR数据，不新增付费生成或依赖。

## 机位与运行

CAM_enter为完整晨峡；CAM_city仰见城与晨云（gao）；CAM_follow水平跟舟；CAM_gorge两岸纵深（shen）；CAM_exit出峡远望（ping）。FOCUS_city/boat、SFX_ape_left/right、ANCHOR_seg_in/out按CONTRACT登记。可选FOCUS_enter/follow/gorge/exit及CAM_boat/rower沿用既有命名语义，供受限观察与组件检查。段锚点只描述有限场景出入口，不宣称已实现无限峡谷拼接。

航行复用BoatCruise，人物/橹复用Rower，全局t重建、减少动态固定舟位。先完成可检查模型与晨景lab，再接正常产品同Canvas云水入境、诗文/手动选句、暂停/重看/受限鼠标观察、单快照翻页与声音。左右猿声另制作并实听，挂点先随模型交付。

## 验收与证据

CONTRACT先登记候选，再同步制作/Node/运行校验与资产。首版scope=quality-sample，建模完成、网页接入和性能分别记录。

Blender每组件检查尺寸、原点、缩放、闭合性、UV/材质和接合，主源独立重开。GLB检查正式节点、PBR、骨骼/舟约束、航线与高度图；缺节点/非法路径/坏高度图等实际坏数据必须被拒绝。优化保留Meshopt原字节及无损WebP原像素核对。

全部GLB及环境合计≤15,000,000B，单图≤2048²；优先共享1K图。候选沿用≤200k文件三角面、纹理含mip≤256MiB工作预算；高度图等另报完整分发。真实浏览器统计主画面/阴影/倒影总calls和面数。

只验桌面1920×1080、1440×900及必要缩窗；固定seed与t=0/8/16/24/32和航线末段，录制连续检查片。验证首帧、航向/吃水、跟随、seek重复、减少动态、404/重试/取消和十次释放。按当前CPU/SwiftShader机器实测并记录帧率/P95；性能目标沿用1920/DPR1至少50fps，模型与运行结果分开记录。

证据放本阶段assets/scene-v01独立修订目录，保留原始截图、视频、JSON、日志、来源与失败尝试；来源登记CREDITS，历史不覆盖。

## v02 精修批次

沿用全部舟/人物/航线与城市构件，以独立副本修改自然组件，实际结果只记HANDOFF。输出名与CONTRACT18.12对应；脚本、组件库与证据分别使用v02目录。

1. 先做右近岸断裂岩壁样段：岸长254m、约48m厚，约45层非等距高程与百余纵向采样；不规则岩柱、错动层面、侵蚀水脚和退台山肩共同决定轮廓。检查闭合体积、0/.22m水线、UV、航线与实际机位。
2. 逐段替换左近岸、左远岸、右远岸；每段独立检查后保存。近岸岩壁高度随分块峰脊变化，远岸保留纵深和出峡窗口。
3. 城台单独细化：保留既有台基四角的63m支撑标高，脚部/腰部做不同尺度裂隙和退台，衔接右岸山肩。
4. 独立制作三种阔叶树原型：约5–8m高、4–7m冠幅，先检查枝干承托、叶冠体积和轮廓。散布与原型分开，根部按修订岩面投射并嵌入5cm，近景成组、崖面留白，预估森林≤90k三角面。
5. 单独细化远山峰脊与沟壑，再烘焙v02米制高度图。河道和近景保留原留空逻辑，避免掩埋舟路。
6. 组件检查后更新已有发布节点；统一制作校验/导出/编码/预算，七机位浏览器检查与必要修正。预估岩壁约50k面、舟城约43k面，剩余预算用于树冠；总门禁维持200k面/15MB。
