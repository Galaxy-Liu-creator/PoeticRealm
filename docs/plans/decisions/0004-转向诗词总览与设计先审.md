# 0004 · 转向诗词总览、写实诗境与设计先审

- 状态：**采纳用户提出的产品转向；视觉细节、技术提案与新版排期待审批**
- 日期：2026-10-01
- 取代：ADR 0001 中旧体验对应的阶段内容与范围取舍；截止日期保留

## 背景

用户认为当前效果偏离主题，要求改为可直接浏览的浮动诗词卡片首页、分意象平滑入场、真实三维诗境、顶部导航、翻页返回、收藏和个人资料。并明确要求先调整 docs，再用 Stitch 或 GPT-image 出设计稿，由用户审批后开发。

## 决定

1. 首页直接显示诗词总览：上部较暗的动态山水题头与行书标题“诗境·一卷山河”，下部独立中国风动态背景与浮动诗卡；不纯黑、不纯白。
2. 取消黑屏印章门禁、强制书房开场、古籍目录选诗和强制纸面生长。已写好的技术实验保留，但不是继续投入的理由。
3. 按诗意配置火烧、广域风雪、云水等入场。诗境返回总览必须翻页；主页不显示返回，其余页面显示。
4. 复杂主体和真实建模用 Blender；水、雾、雪、云、风、天空等自然环境可用 JS / GLSL。不在场景组装目录散写建模算法。
5. 保留 WebGLRenderer、锁定的 three.js、全局可跳转时钟、种子随机、GLB 机位来源、资产预算与许可规则。
6. 增加收藏列表与个人中心；**建议**首版本机保存头像、姓名、可选性别和收藏，暂不引入云账号。此项是待审批默认方案，不冒充用户已确认的架构。
7. 新增 D0 方向重设与 UI 审批关口。未获批前不改前端，不重制 Blender 资产，不把概念图当运行结果。
8. CONTRACT v0.1 的数据字段不在文档阶段直接变更。写实 PBR 输入、程序化地形或必需场景范围变化，实施前按 CONTRACT → 校验 → 资产 / 代码同步迁移。

## 备选及放弃理由

- **继续完善纸面生长和水墨后处理**：复用最多，但不回应用户对首页、真实材质和操作路径的要求。
- **玄幻游戏式国风**：可快速增加刺激性，但与诗境、非游戏化 UI 和文化边界不符。
- **仅做静态背景阅读网站**：适合作为低配降级，不能作为真实三维意境的主要交付。

推荐以“东方山水构图 + 写实材料与光照 + 克制书法 UI”出首轮生成稿；配色、布局和动效强度由用户看图决定。

## 影响

- `docs/设计文档.md` 升级 v3；STORYBOARD、CHECKLIST、路线图和根目录指引同步。
- P0 T1–T5 及证据保留；T6–T9 不再按旧目标继续。可复用的契约与行为验证在新实施计划中重新编排。
- `docs/design/` 保存 brief、参考来源、提示词、原始输出及审批记录；不把未审批图放入 `public/`。
- 旧 ADR 0002 测试策略、0003 GLSL 加载方式继续有效；新增 UI / 本机存储测试覆盖。
- 2026-10-23 截止不变；后续时间窗仅是建议，设计审批延迟时需重新评估，而非跳过审批。
