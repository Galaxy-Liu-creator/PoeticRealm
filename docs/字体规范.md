# 《诗境 · 一卷山河》字体与排版设计规范

## 1. 文档目的

本文档用于统一《诗境 · 一卷山河》项目中的字体系统、文字层级、适配场景与页面使用规范，供后续前端开发、视觉调整和 Codex 自动修改时直接参考。

项目当前已经具备较完整的中国传统文化视觉元素，包括：

- 水墨山水
- 古建筑
- 江河与舟船
- 竹叶
- 月色
- 宣纸质感
- 墨绿色
- 暖色灯火
- 金色流光
- 东方留白

因此后续不应继续通过“大面积行书/毛笔字体”来强调中国风，否则容易造成视觉疲劳、信息层级混乱和“古装游戏 UI”感。

本项目字体设计的核心原则为：

> **宋体做骨架，楷体做文化气质，行书只做点睛，黑体负责功能信息。**

最终视觉目标应从“古风网页”提升为：

> **现代东方数字文化作品**

---

## 2. 总体字体体系

整个项目统一采用四级字体体系。

| 字体体系 | 推荐字体 | 主要职责 | 视觉特征 |
|---|---|---|---|
| 品牌书法字体 | 当前已有行书 / 行楷 | 品牌识别、开场视觉、文化点睛 | 强个性、强书法感 |
| 标题宋体 | 思源宋体 / Noto Serif SC | 页面标题、结构标题、卡片标题 | 稳重、典雅、现代东方 |
| 诗意楷体 | 霞鹜文楷 / LXGW WenKai | 诗词、宣传语、文化文案 | 书卷气、温润、自然 |
| 功能黑体 | 思源黑体 / Noto Sans SC | 表单、导航、按钮、数据、提示 | 清晰、现代、易读 |

字体层级关系：

```text
                    行书
                     │
                  品牌点睛
                     │
          ┌──────────┴──────────┐
          │                     │
        宋体                   楷体
     页面结构标题           诗意内容表达
          │                     │
          └──────────┬──────────┘
                     │
                   黑体
                功能信息 / UI
```

## 3. 字体一：行书 / 行楷

### 3.1 定位

行书不是整个网站的主字体，而是项目的“品牌字体”。

其作用是：

- 建立《诗境 · 一卷山河》的文化辨识度
- 在关键位置提供书法气质
- 形成第一视觉焦点
- 与水墨山水背景形成品牌统一感

### 3.2 适配场景

推荐用于：

- 网站左上角品牌 Logo
- “诗境 · 一卷山河”品牌标题
- 登录/注册开场幕布中央标题
- 首页大幅品牌主视觉
- 特殊转场中的诗境标题
- 少量装饰性书法题字
- 章节卷首题签
- 少量印章式品牌文字

示例：

```text
诗境 · 一卷山河
```

### 3.3 不适配场景

禁止用于：

- 欢迎回境
- 创建账号
- 我的收藏
- 个人中心
- 诗词总览
- 用户名
- 密码
- 确认密码
- 生日
- 性别
- 导航栏
- 表单提示
- 按钮
- 数据统计
- 系统设置
- 长篇正文
- 大段文化说明

### 3.4 使用比例

单页面中建议：

```text
行书视觉占比：5%～10%
```

普通页面最多保留 1～2 个明显行书元素。

### 3.5 设计原因

行书的笔画变化和个性很强，过量使用会导致：

1. 阅读负担增加
2. 页面缺乏视觉层级
3. 容易产生审美疲劳
4. 与复杂山水背景争夺注意力
5. 容易形成古装游戏或模板化古风 UI 的感觉

## 4. 字体二：思源宋体

### 4.1 定位

思源宋体是整个项目的“结构字体”。

主要承担：

- 页面一级标题
- 页面二级标题
- 卡片标题
- 重要功能区标题
- 重要按钮
- 结构性信息

它应成为项目视觉体系的骨架。

推荐字体：

```text

Noto Serif SC
思源宋体
```

### 4.2 适配场景

推荐用于：

#### 页面一级标题

- 欢迎回境
- 创建账号
- 我的收藏
- 个人中心
- 诗词总览
- 诗境详情
- 最近浏览
- 成就与偏好

#### 页面二级标题

- 诗境漫游
- 水墨转场
- 古诗意境
- 沉浸交互
- 账号信息
- 系统设置
- 我的收藏
- 最近浏览
- 文化解读

#### 卡片标题

- 枫桥夜泊
- 江雪
- 早发白帝城
- 山居秋暝
- 使至塞上

#### 重要按钮

可以使用宋体增强文化感：

- 立即登录

### 4.3 字重建议

```text
H1 / 页面主标题：700
H2 / 章节标题：600
卡片标题：600
按钮：600
普通结构文本：400～500
```

### 4.4 推荐 CSS

```css
:root {
  --font-serif:
    "Source Han Serif SC",
    "Noto Serif SC",
    "思源宋体",
    "Songti SC",
    serif;
}

.page-title {
  font-family: var(--font-serif);
  font-weight: 700;
  letter-spacing: 0.08em;
  line-height: 1.25;
}

.section-title {
  font-family: var(--font-serif);
  font-weight: 600;
  letter-spacing: 0.06em;
}

.card-title {
  font-family: var(--font-serif);
  font-weight: 600;
}
```

## 5. 字体三：霞鹜文楷

### 5.1 定位

霞鹜文楷是整个项目的“诗意字体”。

它承担：

- 诗词正文
- 情绪性文案
- 项目宣传语
- 引言
- 副标题
- 文化说明
- 场景描述

相比传统楷体，霞鹜文楷更自然，长时间阅读也更舒适，不会像行书那样抢视觉焦点。

推荐字体：

```text
LXGW WenKai
霞鹜文楷
```

Fallback：

```text
KaiTi
STKaiti
楷体
```

### 5.2 适配场景

#### 项目宣传语

```text
循诗入境，展卷见山河
```

#### 功能亮点描述

```text
循诗而行，漫游千里山河
一卷展开，意境随行
唐风宋韵，诗画相生
身临其境，与诗共鸣
```

#### 诗词正文

```text
月落乌啼霜满天，
江枫渔火对愁眠。
姑苏城外寒山寺，
夜半钟声到客船。
```

#### 页面副标题

```text
输入您的账号信息，继续您的诗意旅程。
```

#### 个人签名

```text
行于诗境，藏一卷山河。
```

#### 收藏页文案

```text
一卷中烟霞，朝夕可对
```

#### 场景氛围说明

```text
江枫渔火对愁眠
独钓寒江雪
轻舟已过万重山
```

### 5.3 推荐 CSS

```css
:root {
  --font-kai:
    "LXGW WenKai",
    "霞鹜文楷",
    "KaiTi",
    "STKaiti",
    serif;
}

.poetic-copy {
  font-family: var(--font-kai);
  font-weight: 400;
  letter-spacing: 0.08em;
  line-height: 1.7;
}

.poem-text {
  font-family: var(--font-kai);
  font-weight: 400;
  letter-spacing: 0.10em;
  line-height: 1.9;
}
```

## 6. 字体四：思源黑体

### 6.1 定位

思源黑体是整个项目的“功能字体”。

所有需要快速识别、点击、输入、阅读的功能信息都应优先使用黑体。

推荐字体：

```text
Source Han Sans SC
Noto Sans SC
思源黑体
```

### 6.2 适配场景

#### 导航

- 诗词总览
- 我的收藏
- 个人中心
- 返回首页

#### 登录注册表单

- 用户名
- 密码
- 确认密码
- 生日
- 性别
- 30天内记住我
- 忘记密码
- 用户协议
- 隐私政策

#### 输入提示

```text
请输入用户名
请输入密码
请再次输入密码
请选择出生日期
```

#### 校验信息

```text
用户名长度为 4-16 位
两次密码输入不一致
密码强度：强
用户名已存在
```

#### 数据展示

```text
12 处
28 首
36 次
```

#### 设置项

- 诗境更新通知
- 精选诗词推荐
- 深色模式

#### 普通按钮

- 取消收藏
- 查看全部
- 编辑资料
- 保存设置

### 6.3 推荐 CSS

```css
:root {
  --font-sans:
    "Source Han Sans SC",
    "Noto Sans SC",
    "思源黑体",
    "Microsoft YaHei",
    sans-serif;
}

body {
  font-family: var(--font-sans);
}

.form-label {
  font-family: var(--font-sans);
  font-weight: 500;
  letter-spacing: 0.02em;
}

.form-input {
  font-family: var(--font-sans);
  font-weight: 400;
}

.form-helper {
  font-family: var(--font-sans);
  font-size: 0.875rem;
  opacity: 0.6;
}
```

## 7. 按钮字体规范

按钮不得统一使用行书。

推荐规则：

| 按钮类型 | 推荐字体 |
|---|---|
| 主操作按钮 | 思源宋体 SemiBold |
| 次级功能按钮 | 思源黑体 Medium |
| 普通 UI 按钮 | 思源黑体 |
| 品牌仪式型按钮 | 思源宋体 |

例如：

```text
立即登录
立即注册
入境
查看诗境
```

推荐使用思源宋体。

例如：

```text
取消收藏
编辑资料
保存设置
返回
```

推荐使用思源黑体。

推荐 CSS：

```css
.primary-button {
  font-family: var(--font-serif);
  font-weight: 600;
  letter-spacing: 0.08em;
}

.secondary-button {
  font-family: var(--font-sans);
  font-weight: 500;
  letter-spacing: 0.04em;
}
```

## 21. 视觉设计原则

整个项目遵循：

```text
90% 克制
+
10% 传统元素
```

中国风不等于所有文字都必须像毛笔字。

当前项目已经存在大量中国文化元素，因此字体更应该克制，以形成视觉呼吸感。
